## 1. [P1] 续跑未核验已保存回答的原哈希，会把改动后的回答重新登记为有效

位置：[run_fi1_r4_qwen.py:154](../tools/run_fi1_r4_qwen.py#L154)、[run_fi1_r4_qwen.py:222](../tools/run_fi1_r4_qwen.py#L222)。

`infer()`只对本次requested范围内的回答检查`task_sha256`，没有先比对既有`summary.task_outputs`保存的回答内容哈希。汇总阶段又遍历全部任务，对当前文件重新计算哈希并写入完成摘要。因此，一条回答的内容被改动后，只要保留任务身份与complete标记，就可能被当成原来的有效回答。

真实回答的临时副本复现：将最后一任务的AB/BA由`A/B`一致修改为`B/A`，同步修改顶层和逐顺序raw字段；不改任务SHA，不调用Qwen。执行只要求首任务的`infer(count=1)`后，新摘要接受改动；真实`apply()`随后也接受该副本，交换次数从 **72变成73**。原始任务与结果未修改。这不仅是一个摘要显示问题。

修复要求：恢复前核验原完成清单中**所有**已有回答的内容哈希、任务与提示词身份；任何不符拒绝恢复，不能重签为旧结果。未完成任务另用明确的逐顺序日志合同；修改过的答案只能作为独立新产物，不能冒充原推理。

## 2. [P2] 完成后重复执行会改写摘要，使下游依赖失效

位置：[run_fi1_r4_qwen.py:225](../tools/run_fi1_r4_qwen.py#L225)、[continue_fi1_r3_r4.py:92](../tools/continue_fi1_r3_r4.py#L92)。

已在真实inference目录的临时副本中复现：任务哈希清单不变、完成摘要哈希变化、预测所引用摘要哈希失效。

修复要求：已完成且验证通过的阶段只读返回；区分“本次调用没有新推理”与“本实验曾完成推理”。运行访问日志另存，不能改写冻结完成摘要。总控先验证终态及依赖后返回，不将无副作用重复调用写成失败实验。

## 3. [P2] 总控尝试恢复部分输出，但下游阶段拒绝已有目录

位置：[continue_fi1_r3_r4.py:99](../tools/continue_fi1_r3_r4.py#L99)、[run_fi1_r4_qwen.py:238](../tools/run_fi1_r4_qwen.py#L238)、[evaluate_fi1_r4_qwen.py:49](../tools/evaluate_fi1_r4_qwen.py#L49)。

修复要求：明确支持按扫描回执恢复，或者为每次阶段尝试分配独立目录，只有完成验收才更新完成引用。不能通过删除旧目录或忽略哈希来“修好恢复”。
