# 局部区域提议覆盖与样本供给：诊断前冻结

开发200原物理五折、原1599父N/T、原GD10最多六帧、0.15米邻域及可见性。只做提议和训练范围诊断，不训练、不执行新的学习删除、不改骨干/轨迹/SL/AP。GT不产生区域，不围绕四个既有见证定制。

生成阶段仅读取processed原始XYZ/RGB/法向前9列、原父/邻域、冻结8近邻和原六帧可靠姿态组数，以及GT-free N/T分歧角色。禁止读取原superpoint列9及后两GT列，禁止读取标签、错误清单和概率提议。区域仅包含父内至少两组可靠可见点；未观测点仍属于保留域。

固定三尺度空间范围.05/.12/.30米，各用0与半格偏移，总六种分区。格内再按原始点邻接、距离<=.05米、颜色距离（归一化RGB欧氏距离/√3）<=.12/.22/.35、法向差1-|dot|<=.15/.30/.50形成连通分量。几何/颜色约定复用旧split-grow；不使用原segs超点，格不是不可拆分动作。缺失法向不作为硬切边依据。所有尺度直接原始点输出，无固定2cm决策单元。

每种分区按1—15、16—63、64—255、>=256点轮换供给，并交替优先覆盖点数与空间分散，N/T分歧最多.25加分，不成为资格。固定预算48/96/192，主预算96；每分区最多8/16/32个区域，精确相同点集跨分区去重。不因GT诊断更换主预算或阈值；预算未用满也不按GT补样本。预算前原始区域一并封存以定位区域划分和预算分别损失了哪些机会。

全部200场景生成及代码/区域哈希封存后，才进行五套原外层训练范围诊断；每套只读其160训练场景，留出40场景不参与该套汇总。五套互相重叠，总和不冒充独立样本，200场景并集是开发训练诊断，不是OOF方法收益。比较同范围下原G内交叉缓存块（旧float16边界保持）和显式float32>=.8重建块，仅修正新对照的数值边界；不改原结果/网络。

GT标签统一稳定父：沿原目标匹配、父纯度>=.6；其他父全部身份不确定，不强制分配修复目标。稳定父区域分类为纯目标、纯已知污染、目标—污染混合、涉及未知标注；报告身份未知父的区域。严格安全动作要求整块全部已知其他实例，删后>=100点且IoU改善。按区域统计样本可重叠；实际删除点计数必须去重。

诊断报告单区域和联合纯块两种可行筛查，均按真实点集与完整NT最佳IoU比较（>=.02及严格>.75/.78/.90/.95/.98）。另报告可靠可见已知污染逐点筛查、提议覆盖内正确点筛查，以分离可见→覆盖→整块损失。GT筛查不是模型输出、不是全部组合最优上界，未知标注保留。汇报场景/父/来源/尺寸/类别、原父好候选、混合与未知样本及每套训练范围。

主预算96的供给检查每套训练范围都应满足：>=1000区域，>=250安全动作，>=40安全父/20安全场景，>=25个64点以上安全区域及>=8个256点以上安全区域；混合区域>=15场景；身份未知>=100区域、20父、10场景；可行整块筛查>=10个NT池增量>=.02目标且>=5场景。此门是本地供给可学性筛查，不是方法有效或AP验收。未达标就停在提议阶段；即使达标，本轮仍仅交付供给报告，后续同源归属学习另行冻结。
