## 检查与结论

- 从已批准的划分重新核对200训练／55开发验证／5诊断、五折主场景隔离、六个模型的实际拟合/推理扫描、数据来源、文件哈希和类别映射。5诊断主场景与训练重叠是既有诊断定义；它们未参与拟合。
- 训练GT目录恰为200扫描，60验证/诊断特征文件不含训练标签。特征只来自冻结视觉证据及基础来源属性；前轮全部特征/权重独立审计的完成清单及输入身份再次核对。
- 对全部200训练扫描、19,931个几何，用稀疏掩码矩阵相乘计算GT交集，独立重建同类最大IoU及最小100点规则。全部2,909,563条成员目标与原标签完全相同，误差0。前轮仅抽查1,600几何的限制在本次目标检查中已补齐。
- 另行从批准的训练扫描组装训练矩阵，独立重建扫描→几何→类别权重；检查保存模型的实际超参数，重训五折及全200共六个HGB评分头。未调用原R2训练或目标构建函数，仍使用同一sklearn实现。
- 六个重训模型对260扫描的完整预算前成员推理，最大分数差异1.110223e-16，处于浮点舍入量级。原始模型重放曾完全相等；本次独立重训不声称模型字节或分数字节完全相同。预算内成员、类别、原始别名及排序均保持一致。
- 使用独立重训的分数重新评AP。55开发验证为32.250098／38.983537／43.045324，5诊断为60.871549／66.993397／70.632596；六项指标与R2原结果逐值完全相同。AP沿用同一ScanNet评测器，不是独立的AP算法实现。

新增5项审计测试通过，覆盖错误折分配、诊断标签混入训练、模型遗漏/重复，以及稀疏交集与布尔掩码IoU的一致性。

## 代码检查的边界

原训练加载器依赖生成阶段的冻结回执；前轮独立数据审计由顺序流水线调度，并非每次手工调用训练命令都会自动触发。本次独立审计补充了实际批准划分、全量输入文件、全量目标和独立重训检查。这是扩大审计覆盖，不是发现原结果已错配或宣布通用入口能拒绝一切损坏输入。未来变更数据/代码时须重新生成身份并重做相应审计，不能仅沿用“测试通过”标记。

仍有方法边界：55验证有历史使用，不是盲测；冻结D-v3监督上游见过部分训练折主场景，更早Legacy/骨干监督未完全追溯；NCS历史Alpha缺旧RGB字节哈希。本轮没有重训上游视觉模型，不能称整系统OOF或完整视觉推理独立复现。
