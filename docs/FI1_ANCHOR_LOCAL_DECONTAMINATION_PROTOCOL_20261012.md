# 锚点约束局部去污染：小规模配对实验

日期：2026-10-12。用户指定几何优先，固定 SL 权重及评分协议。

只在既有开发200内，按原物理场景五折×旧90/新110分层，每格取输入齐全且固定哈希最先的一个场景，共10场景。每场景最多4个N、4个T，按点数100—100000和固定哈希选择；同点集只选一次，失败锚点不替换候选。候选不按GT污染、语义、模型分数或改善结果挑选。

每个父候选独立选择一个原始超点作核心，至少20点且95%在父内；最多检查5个靠近父中心的核心，要求既有掩码在至少两个位姿组覆盖95%可见核心。它是推理可得几何锚点，不保证对象身份，不使用N/T交集。GT身份不足、混合核心的比例在封存后单列。

使用原有30帧范围，最多3个独立位姿组。同一候选的两臂共享核心、原GD框、视角、SAM ViT-B权重、单mask解码及裁剪算子：旧臂使用缓存mask；新臂在原GD框上添加3个核心正点重新提示。没有SAM2跟踪、新帧、负点、容量或参数扫描。旧框提示另外重放，mask IoU须>=.999，并核对旧RLE回投点集精确相同；这只是缓存身份检查，不是第三实验臂。

局部可修改域在读两臂输出前固定：父内距离父外原始场景点<=.15m的点。只删除至少两个独立位姿组有可靠可见排除证据的点；实际深度与投影差<=.02m，RGB mask外至少2像素，任何有效视角正支持均否决删除。核心、遮挡、缺测、未知和未观察区域保留。质量<=.88、稳定度<.95、可见核心不足或核心覆盖<.95的视图弃权。删除超过父20%时整个动作回退，不截断预算。两臂都保留原NT；所有候选和失败回退都报告，不能只看双臂均成功的子集。

先封存计划，再执行两臂观测和裁剪，全部几何封存后读取10场景白名单GT。报告严格>.50/.75/.80/.85/.90/.95的完整NT池增量、已有覆盖目标最佳IoU变化、跨档提升、相对同父及旧mask臂的效果；记录删除污染/目标点、锚点错误/未知、身份漂移、重复NT/新候选、质量弃权和逐场景/N/T/原折稳定性。可见区域mask边界IoU是诊断，不是实例AP。

在查看GT前冻结以下几何接入门：新臂至少5个接受动作、覆盖3场景；至少3个目标在至少2场景产生完整NT池最佳IoU提升>=.02，或跨过>.75/.90/.95覆盖线；且至少3个目标在至少2场景相对旧臂全池最佳IoU改善>=.01；完整NT池最佳IoU变化总和相对旧臂为正。删除污染占比>=90%，可靠锚动作合计目标误删/父内目标<=1%，任何动作目标误删<=5%；未知锚动作<=10%，可靠锚身份漂移为0，同父>.75覆盖失守为0。提升已覆盖目标可以过门，不要求必须新增>.75目标。

门失败就封存失败结论，不按结果调阈值、增帧或追加自身语义。门通过才按另行冻结的接入合同获取新点集自身YOLO/Alpha，保留当前对应折B26/L模型，完整重算扩池上下文；比较原SL、扩池上下文只选NT、允许新候选进入K800，封存全部预测后检查双AP、各IoU档原覆盖/正分、424子群与预算退出。后续不能继承父类别/分数，原NT保留也不保证K800保护。本实验不训练或修改生产，也不使用55/312/已消费保留100调参。

这是暴露开发集的小规模机制实验。缺乏GT标签的区域不能默认为安全，原始超点也可能错误；接受门是本版保守工程标准，不是普遍理论界限。不将边界诊断、池覆盖或GT oracle称为最终AP。
