# 第二点逐类评分消费端：实现与首轮结果

日期：2026-09-10。用户已授权在冻结第一点、固定类别成员的条件下实现并验证评分消费端。

**实现已接通，首版统一评分未通过 AP 验证，保留原 B1。** FI1-A 质量已真实进入下游计算，当前不再只是 `score=null` 的接口。新增语义、质量、同类重叠特征改善了独立掩码质量预测误差，但整体 AP 下降。来源对照定位到 union 重评分的明显负效应：许多几何质量较高的 union 已有同类预测覆盖，逐掩码质量回归仍将它们抬为高分候选。下一项应针对额外候选的同类边际贡献和分数可比性，而非重训第一点或继续增加视觉模型。

## 1. 本轮完成了什么

- 新增纯评分核心、运行器、独立审计器、测试和本报告，共5个文件；旧 FI1、B0/B1/B2、视觉导出和 evaluator 源码不覆盖。

- 原 B1 的 **66763个成员、掩码、类别、顺序、原始分数记录完整保留**，实验输出只修改最终 `score`。未补类、未删候选、未改 top-k 预算；sentinel 与小掩码保留原分数。
- 复用2283个几何的已审计视觉证据，从中对实际已有 B1 的 **1864个几何、13054个前景成员、92个场景**评分；其余53709列保持B1分数。新评分不是完整全来源视觉池的统一重评估。

## 2. 方法与比较设置

共同使用固定容量 `HistGradientBoostingRegressor`：80轮、7个叶节点、learning_rate=0.05、min_samples_leaf=20、L2=1、early_stopping=false、固定随机种子。不搜索参数。

训练目标为同类有效GT的最大IoU在项目 evaluator 九档严格阈值0.50–0.90上通过的比例，再减去原B1分数。输出为：

`new_score = clip(original_B1_score + predicted_residual, 0, 1)`。

这是逐掩码质量代理，不是精确AP损失；同一目标的多个正确掩码都可以得到正目标。损失按场景等权、场景内几何等权、几何内成员等权。类别编号、场景编号、fold、GT及FI1-D分数不作为特征。原标签图、bbox、完整Alpha各自保留，不做argmax覆盖。

| 分组 | 输入 |
|---|---|
| S0 B1 | 原始完整预测与分数 |
| S1 semantic | B1分数、自身逐类视觉证据、点数、来源、可见性；17维 |
| S2 quality | S1 + FI1-A独立质量与缺失标记；19维 |
| S3 quality context | S2 + 同类邻居支持、重叠及证据缺失统计；33维 |

来源标记已经存在于S1–S3；下一步不能再把“加来源标记”当成尚未做过的修补。重叠特征也已存在，但没有改变“重复正确掩码都获得正质量目标”的定义。

**数据与隔离范围：**仅使用ScanNet200 official100已有数据与已独立核验的GT缓存，没有读取validation60/val312。新下游头按场景五折留出，其fit/test场景互斥；历史FI1和B1的监督依赖未重新隔离，因此这是明确标注的固定上游开发诊断，**不是整个系统的严格嵌套OOF或独立泛化证明**。历史质量元数据中的 `use_as_training_feature=false`、`nested_exclusion_verified=false`保持原样，新实验显式记录其仅用于该开发诊断的范围，不据此打开生产入口。

分组、超参数及选择规则在生成新训练目标前写入 `experiment.json`；本轮已经知道此前历史归因结论，不能称完全未看过数据的预注册。选择13054列只依据已有视觉、原成员与点数，无GT筛选。

## 4. 质量进入了计算，但训练目标与最终贡献不同

| 分组 | 所评分成员质量代理MSE | 按训练权重计算的MSE |
|---|---:|---:|
| B1 | 0.020206 | 0.064519 |
| S1 | 0.017360 | 0.045599 |
| S2 | **0.015686** | 0.041110 |
| S3 | 0.015715 | **0.038415** |

这是对固定诊断数据上代理目标的误差，不是AP，也不消除历史上游监督依赖。**误差下降与AP下降同时发生**，已经否定“预测独立掩码质量更准就能自动带来更好最终排序”的简单假设。

推理时按几何循环置换质量值，S2有3853列、S3有3267列发生分数变化，证明质量并非只写入元数据而未被模型消费。该探针不改变训练、不计算额外AP、不用于选参数。

进一步回查完整B1同类候选池：

- 13054列中，516列拥有同类有效GT且IoU>0.5；它们对应288个不同的场景/类别/GT目标。
- 516列中358列有其他IoU>0.5的同类预测，241列有其他不低于自身IoU的同类几何。它们仍被赋予独立质量正目标；这些计数不是互斥错误类型。
- **union的190列质量正例中，189列有其他同类预测覆盖，170列有不低于自身IoU的同类几何。** 这189列的平均分从B1的 **0.005877→S3的0.363724**。几何准确的重复预测被明显抬高，并不等于增加了有效目标覆盖。
- 对union而言，质量代理MSE从0.143080降至0.073762；这与重复候选提分可以同时发生。模型完成了其回归任务，但该任务未充分表达AP中的重复代价。
- 分数截断也产生了副作用：所评分成员零分数从982变为S3的8760，1个质量正例被压到0。这些平局确实存在，但没有单独量化它们造成了多少AP下降，不能把全部损失归给截断。

另外，只更新部分视觉覆盖成员，而保留其余成员旧分数，会产生新旧分数可比性问题。当前没有将此项与目标定义独立分离，不能声称已经精确拆出两者各自造成的损失。

## 5. 来源对照定位了主要负效应

在四组主实验结束后，固定已经训练好的S3输出，分别仅应用native、track、union来源的新分数，其余列保持B1。三组均计算，没有新模型/参数搜索/按GT挑行。这是**事后归因，不是选出的新方法**；增量不能相加。

| 只修改的来源 | 改分列数 | AP | AP50 | AP25 | 相对B1 AP |
|---|---:|---:|---:|---:|---:|
| native | 10774 | 32.967618 | 40.525945 | 44.029067 | +0.211878 |
| track | 701 | 32.508237 | 40.065438 | 43.525305 | −0.247503 |
| pair_union | 692 | 31.731267 | 38.955500 | 42.266511 | **−1.024472** |

这支持：**本版同一评分规则对来源的效果不同，union重评分是明确的主要负效应来源。** 结合上一节重复统计，下一项应解决union/track的同类边际贡献，而不是直接抬高它们的几何质量分。此比较没有进一步隔离S3中的单个特征，也不能单独证明FI1-A在native上带来+0.211878。

native-only的小幅正值仅用来理解链路，不直接晋升为正式方法或独立验证结果。

## 6. 下一项改动边界

保持第一点、原B1、多类别成员与已有视觉证据固定。优先修改第二点中额外候选的**训练目标及与已有同类候选比较的方式**：

1. 区分“单个mask与GT吻合”与“相对已有同类预测是否增加覆盖或提供更高质量的有效预测”。不再让已有同类高质量预测充分覆盖的额外候选，仅凭独立IoU就得到很高最终分数。
2. 明确同类竞争发生在完整B1预测池。当前模型有邻居原始视觉支持，却没有直接表达完整B1中同类竞争者的最终分数及其与自身的差距；这是后续需要落实并验证的输入，而不是继续堆视觉模型。
3. 保留质量作为证据，把逐类额外贡献作为需要检验的目标；GT只能用于训练标签/评测，推理不能根据真实IoU挑赢家。处理重复的任何目标也需检查目标切换、多掩码精度与召回的权衡。
4. 避免仅凭独立质量回归输出替换一部分预测的排序尺度。新旧分数的统一标定及零分平局应单独验证，不能把当前native-only诊断直接作为参数选择结果。

本轮不改变几何、不恢复新类别、不调用新Qwen、不重训FI1。新的下游方案仍需单独固定对照；当前失败头不继续调参直到变正。
