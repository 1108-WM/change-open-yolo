# 完整固定R3b成员AP对照：运行前协议

2026-09-15用户在20主场景ΔAP诊断后授权启动完整成员对照。本实验检验同一R3b头下推理成员扩展的条件净收益；不是重训、候选质量改造、Qwen或新前端实验。

## 固定与变化

- 原26维R3b、完整R1上下文、原模型、浮点分数、点集和别名保持不变。训练侧按原主场景五折使用留出预测；非训练扫描用原full200。
- 控制组：原R1全部成员、原R3b评分、原600预算。
- 对照组：仅R0预算前成员，从完整R3b预算前分数中精确索引，再重选600条。排序仍为分数降序、原生别名优先、geometry_key、class_index。成员不足600时保留全部，不复制或补造候选。
- 不删除上下文邻居、不重归一化、不重训R0专用模型。结果只解释为固定R1训练头下的推理成员效应，不是两种训练分布各自最优对比。

## 角色与顺序

260扫描固定为：五个训练留出折各40，开发55，重叠诊断5，依次串行。训练五折分别报告，不平均成官方“train200 AP”；其类别分母和模型不同。开发55为主要开发比较，非盲测；诊断5允许已知的训练主场景重叠，单列且不能宣称独立泛化。val312与当前val48不在本次评价范围中，也不用于搜索阈值。

历史R2条件C0高于扩类R2，但不预设R3b下结果方向。无论正负均完成所有七组，不按早期AP改成员集合、顺序或预算。

## 核验

每扫描：核对原成员、别名、模型/折与特征/上下文的哈希绑定；从模型重放全部分数和受限成员分数，要求逐项精确相同；原top600精确重放；独立“先过滤再排序”与对照一致；保存受限预算前成员、两组预算后成员、来源/别名/递补统计。

每扫描读取已审计点集及GT，逐点索引域和几何hash核对，重建实例直方图/关联；原组关联与历史稠密关联缓存逐字段一致。每组按固定seed `fi1-r3b-full-member-dense-20260915|` 加场景名hash选最小场景，针对两组分别执行原稠密关联，单次掩码矩阵上限400MiB。

每组使用同一原ScanNet200有类别AP/AP50/AP25、198前景类别、原忽略区域/最小100点/IoU阈值/同分处理。计算路径复用已核对的AST原函数，仅跳过重复的False初始化赋值；不修改原评测文件。原组AP全数组和标量与历史精确重放；对照组AP另外用未加速的原始函数核对数组。NaN有效类别分母固定；不把未定义改成零。
