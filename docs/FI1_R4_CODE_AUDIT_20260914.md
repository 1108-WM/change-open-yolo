## 已检查的行为

- `fi1_r4_qwen_core.py`：全 Alpha argmax 与 R2 当前类二选一；替代类必须已在同一几何的预算内成员中，不能悄悄退化为局部 Alpha 次优。相同分数不调用；不从 R3 分数或 GT 选择任务。
- `run_fi1_r4_qwen.py`：冻结 55/5 角色、R2 full200 预测、模型文件、几何/视觉请求、RGB 内容与代码哈希。严格保持多类成员，只在两次分别回答 B/A 时交换两成员原分。非法输出、拒答、顺序分歧及运行错误保持原分。
- 双顺序共享同一组图像、只交换类别名称。每个顺序独立保存原文/提示词摘要/时间/token 数；调用前写尝试标记，若进程中断留下未完成尝试，恢复时记失败而不再次调用该顺序。
- 推理有进程锁，恢复时验证任务和代码身份、运行环境；准备/推理/应用入口设置文件访问保护，拒绝 GT、训练特征标签、R3 模型与 AP 资产。没有把 Qwen 自报 confidence 当评分。
- 应用阶段对全部成员执行独立分数交换重建，要求身份、类别、别名、列表顺序及每几何分数多重集不变。真正完成该重建需等待实际推理结束，当前仅完成测试和代码检查。
- `evaluate_fi1_r4_qwen.py` 单独评测，计划将缓存关联双向更新与全60扫描新点集掩码关联逐项比较，随后重放原R2 AP。该真实评测验收尚待运行，不能提前写成通过。
