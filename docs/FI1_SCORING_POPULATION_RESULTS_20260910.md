# 第二点逐类评分：完整候选池、代表样本与特征入口

日期：2026-09-10。本轮落实了逐类评分的数据准备与特征计算，并运行完整 official100 候选重建、独立审计和冻结样本的 GT 覆盖诊断。没有训练新评分器、生成最终分数或运行新 AP；不能将本轮称为第二点已经取得 AP 提升。

## 1. 已经改变了什么

旧准备目录只覆盖 B1 既有几何和通过历史门槛的 refined。现在恢复所有临时细化候选，使被拒绝、退化和没有改变的案例都能进入诊断与后续证据请求。

| 项目 | 数量 |
|---|---:|
| 原唯一几何池 | 9,729 |
| 新恢复的不同点集 | 688 |
| 当前完整唯一几何池 | **10,417** |
| 完整保留的 B1 语义成员 | **66,763** |
| 所有 union 的临时细化记录 | **1,501** |
| 相交几何对 | 29,726 |
| 冻结代表样本 | **333 个几何 / 92 个场景** |

原 C-v2 对 1,501 个 union 产生 1,038 个发生改变的临时细化、452 个完全未变的结果、11 个因点数不足回退的结果。最终仅 42 条通过门槛，且旧流程只给这 42 条保存了点集文件。本轮根据原始 raw superpoint、已保存的 OOF 原子动作和原连通性规则重建全部临时结果，逐个匹配历史临时点集 SHA-256、点数和删除数量；通过门槛的 42 条另与原保存文件逐点比较。

688 是相对原 9,729 个几何新恢复的唯一点集数，不等于被拒绝的记录数。相同点集只保留一个几何，同时保留全部来源和临时细化别名。B1 成员逐字节恢复，既有 mask、类别和分数没有改写。这些拒绝候选只用于研究，不加入生产预测。

重建只访问 processed NPY 的前 10 列（xyz、RGB、normal、raw superpoint），不访问末尾 GT 列；历史监督产物只提取明确列出的身份、模型输出与动作字段，不把其中的 label 字段用于采样或特征。

随后冻结[GT 诊断合同](experiment_summaries/fi1_scoring_population_20260910/sample_diagnostic_contract.json)，只读取这些样本所在的 official100 内 92 个场景；没有访问 validation60/val312，也没有据结果改动样本。

该检查保留全部自身 B1 类别，不取 top-1；新几何没有类别时单列缺失，不继承父类别，也不直接计为识别错误。这些数值不是完整 Alpha 的准确率或最终 AP。

所选样本涉及 92 条非空操作的细化别名。以父 mask 的最佳有效 GT 为固定目标，按 IoU、交集点数、GT ID 排定目标后：**54 条改善、32 条退化、6 条没有有效父目标**。每折都有改善和退化、语义命中和漏类案例。配对数是别名数，不冒充独立几何数。

这样，下一阶段可以同时检查“几何好但类别漏掉”“类别正确但几何差”“几何改好却重复”等机制，不再只围绕上轮白板或通过门槛的 22 个新几何展开。

## 3. 已实现的逐类特征入口

新入口为 `tools/export_fi1_class_scoring_features.py`，每个几何保留完整 198 类，每类形成 **36 维**输入：

- 自身原低粒度标签图票数、bbox 分布、完整 Alpha cosine、各自距最大类的差值及 Alpha 视角/尺度离散度；
- 点数、来源、有效视角比例、可见率、相对于父掩码的保留比例等原始几何/视觉信息；
- 所有相交唯一几何的连续 IoU、同一个类别 c 的邻居支持、比当前类别支持更强的邻居最大 IoU；
- 每种证据的可用邻居数和缺失邻居数。

邻居逐类计算：比较 `m 的 chair` 与 `邻居的 chair`，不会使用邻居最高类概率代替当前类别，也不根据类别无关重叠硬删对象。相交图按唯一几何计算，多个语义副本不会重复放大邻居数。缺失支持保留 null 并显式计数。

没有手工把 YOLO/Alpha 相加成为最终分数，也没有用 FI1 最终边际分数相乘。B1 分数、FI1-A 质量和 FI1-D 最终分数保留在独立历史元数据；当前特征中的 `independent_geometry_quality=null`，直到其模型及上游隔离真正通过验证。`score=null`、`label=null`、`training_ready=false`。

已有 `scene0027_01` 的 69 个真实完整 Alpha 几何已通过此入口，产生 **13,662 行 × 36 维**特征，并独立重算每行自身证据、几何信息和同类邻居统计。新采样规则独立于该调试场景；这 69 个几何恰好不在本轮 333 个代表请求里。因此代表请求的完整新视觉证据目前 **0/333**，已经生成明确缺失清单，不能声称代表样本上的评分验证已完成。

## 4. 为什么尚未训练新模型

历史 FI1-A 的独立质量已经存在，并非只能找到 FI1-D 的最终分数。本轮按实际点集身份将 **9,707** 条 FI1-A 记录关联到 B1 既有几何；另有 1 条历史记录不在当前 B1 范围，单独记录，没有模糊匹配或填零。

但“原记录是 OOF”不足以让它成为下一层模型的安全 OOF 输入。例：新模型外层留出 fold 0，训练数据中有 fold 1 的一行；该行的历史 OOF 质量由留出 fold 1 的模型产生，其训练或校准却可以包含 fold 0。于是新模型的训练特征间接依赖它准备评估的留出场景监督。

根据 35 个已核验文件哈希的 FI1-A/C/D 模型及其历史 fit/calibration fold 元数据，输出 **140 条不应直接复用的路径**。这些是针对新嵌套训练的依赖检查，不是重跑模型或断言历史 AP 全部无效；模型训练行、特征和预测尚未独立回放，C/D 的更上游依赖也不能仅凭本级 fold 标记获得认证。

已生成 **15 组上游重建任务**：5 个单折排除集合用于外层验证特征，10 个双折排除集合复用于 20 个有序外层/内层训练任务。任务明确列出 fit、calibration、排除场景，要求候选选择、几何细化、FI1-A/B/C/D 和需要使用的语义基线在同一排除集合内重新建立。任务清单本身不授予训练就绪状态。

除了分数，上游监督产生的候选选择和 refined mask 也需要相同排除规则。本轮恢复的是历史诊断候选池，不能通过把旧分数字段删除便宣称整个训练集已经隔离。
