# R2 首版训练约定（2026-09-13，尚未训练）

R0/R1首轮55开发验证已完成，R1直接扩类AP下降。本页固定后续R2的首版做法；不改变已经评过的R0/R1类别集合、直接评分或预算，不从55验证中搜索超参数。训练需等待official100与NCS-train100全部自身语义证据就绪。

## 成员、划分与特征

训练开发池200扫描／139主场景，沿用`approved_split_v1`的5个主场景分组折。55开发验证不参与拟合、早停、特征选择或超参数搜索；5个重叠诊断不用于独立收益判断。旧受监督D-v3上游保持冻结，所有折均有上游已见扫描，因此只能称固定上游的下游折外评分，不能称整系统OOF。

“固定R1成员”指预算前的唯一点集—前景类别集合。每条成员都获得新分数，再应用相同每场景600预算和同分规则；预算内成员可以随分数变化。不得仅重评R1预算内600条，也不得新增类别、换点集、增加NMS。逐场景绑定R1 eligible清单哈希，训练后检查成员集合完全一致。

首版使用20维自身语义及基础来源特征：R0/R1直接分数、YOLO归一化票数、Alpha softmax分数、Alpha余弦、Alpha视角尺度标准差、YOLO/Alpha类排名、各源当前类与最高类的差值、各源分布熵、两源JS散度、两源首类是否一致、log(1+点数)、4个来源存在标记、2个缺失标记。类排名按分数降序、类编号升序，以197归一化；缺失数值填0并保留标记。来源可多热，原始别名保留。不使用类别编号作为连续数值特征，不加入D-v3最终几何排序分数、Qwen或GT邻居特征。

## 监督与模型

监督为当前点集与同类别有效GT实例的最大IoU；不存在同类GT时为0。GT实例及预测最小规模遵循当前ScanNet200评测器设置，掩码低于评测最小规模时目标为0。原始GT绑定使用与R0/R1验证相同的逐点重建方法；标签只写入训练角色，不混入视觉证据账本。

同一扫描总权重相同，同一扫描内每个几何总权重相同，几何内部各类别成员等权；不把同一几何的198类误当作198个独立实例。目标和输入不按55验证分布重标定。

首版固定`HistGradientBoostingRegressor`：squared_error、learning_rate=0.05、max_iter=100、max_leaf_nodes=7、max_depth=3、min_samples_leaf=100、l2_regularization=1、early_stopping=False、random_state=20260913。训练5个下游折外模型并报告各折有效GT及正目标主场景数量；再在完整200扫描拟合部署评分头，开发验证只执行这一份固定设置。预测裁剪到[0,1]，沿用R0/R1 float64排序及同分规则。

这只是低容量逐类质量校准基线，不声称它直接优化AP或解决同类竞争。R3才单独比较同类排序/贡献监督；R4再独立引入Qwen证据。若首版失败，保留全部结果，不按55验证结果隐式修改本页并覆盖产物。

## 首次拟合前补全的数值定义

2026-09-13：official v2 的 100 扫描独立重建审计通过，分数最大绝对误差为0。开始实施首版 R2。以下数值细节在首次 R2 拟合和 AP 前固定：熵和 JS 使用自然对数；分数差为当前类概率减该模态最高概率；缺失模态的数值、JS 和首类一致性均置0并保留缺失标记；Alpha 标准差使用既有全部有效视角/尺度余弦的总体标准差。特征使用 float64。

权重先使每个扫描总和为1，再使扫描内各几何等权、几何内各类别等权；每次拟合时仅在该次训练行上归一化到平均权重为1。这样固定 L2=1 的绝对含义，不让每个扫描类别成员数量决定整体权重尺度。五折的分箱与模型均仅在本折训练扫描拟合，部署评分头仅在全200训练扫描拟合。实现使用本地 sklearn 1.3.2；没有超参数搜索或早停。
