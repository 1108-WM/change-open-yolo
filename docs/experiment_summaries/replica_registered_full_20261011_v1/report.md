# Replica：OpenYOLO3D 基线与登记生产 Full 冻结迁移评测

**复现口径修正：** 论文Replica基线为23.7／28.6／34.8%。本轮是本地重生成候选对照，另有mesh／point cloud输入类型及历史NMS差异，不能称论文原配置精确复现。详见[协议核查](paper_protocol_audit/report.md)；下述原始数值与产物保留。

日期：2026-10-11。8 个标准场景（office0–4、room0–2）全部完成真实预测和封存后评测，没有训练或调参。

**结论：Full 的类别 AP 相对原配置基线增加 0.291908 个百分点，实际输出去类 AP 下降 1.334591 个百分点；本轮没有实现双口径提升。** 不替换生产方法，也不改变固定 SL 的几何开发主线。

## 方法与指标

Full 使用登记的 GD10＋历史 official100 D-v3 七模型＋GD10 匹配训练597 B26，来源 NTUU′，K800；没有调用开发 S、C 或 SL。保留生产 native-only 非对称资格及 D-v3 非硬准入接口。本次验证的是完整生产配置冻结迁移，而不是单模块归因。

使用原 Replica 48 类词表、官方类别 ID 与原评测器。AP 为 IoU=.50:.05:.90 的平均，另报告 AP50 和 AP25；保持严格 IoU 比较、100 点最小实例及原 ignore 处理。下表均为百分数。

## 数据与迁移限制

- 本地数据入口 `data/replica`，完整原网格点域，每场景 200 个原始 RGB-D／pose 帧，深度尺度 6553.5。没有采用 Open3DIS 半采样掩码／超点。
- 历史 `output/replica/replica_masks` 缓存缺失，两方法共用冻结本地 `scannet200_val.ckpt` Mask3D 在完整网格上重生成的候选，保持原 .02 阈值和 .1 NMS。因此这是可复现本地基线，不是论文旧候选缓存的精确复现。
- Replica 网格为四边形。仅在隔离副本中扇形三角化、补算法向后生成超点（segmentator .01／min20）；所有原 XYZ、RGB、顶点及点序保留，原数据和 GT 未修改。
- 基线保持原 Replica YAML：每帧观测、可见深度差 .4、top40 视角、每几何一个投票类别。Full 保持 GD10 每10帧、深度差 .05、自身 YOLO top40、Alpha top20 和三尺度 0/.2/.4。
- 48 类适配只改变语义向量维度、背景索引及类别 rank 归一化分母47；在完整成员池计算原20＋6维特征，冻结 B26 评分，原 tie rule 选择800。没有 Replica 标签训练、调参或类别例外。
- K800 指800个几何—类别成员；基线每原生几何仅一个类别。两配置的成员预算和观测不同，不能将完整差值全部归因于几何或竞争评分。
