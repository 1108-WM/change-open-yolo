# Replica baseline / registered Full transfer protocol

All eight standard scenes are fixed: office0–4 and room0–2. Each has200 original RGB/depth/pose frames. Predictions are produced without GT; raw GT is read only after both methods' prediction receipts are sealed.

Full is the registered production GD10 + historical official100 D-v3 seven models + GD10-matched train597 B26, NTUU′, global K800 geometry/class members. It does not use S symmetric eligibility, C or SL. Frozen models are not trained or tuned on Replica.

Replica has48 foreground classes. The adapter uses the original Replica vocabulary and evaluator IDs, depth6553.5, and background48. Full retains ScanNet production frequency10, visibility tolerance.05, own YOLO top40 views and Alpha top20 views with SAM ViT-B and scales0/.2/.4. Own features change only their class-vector dimensions and normalized rank denominator to47. Competition features still describe the full eligible member pool. The frozen26-input B model scores that pool; its original tie rule selects800 members. D-v3 scores retain their original role, including the production interface that does not use D=0 as a hard B26 output gate.

The historical `output/replica/replica_masks` is absent. Both methods share proposals regenerated by frozen local `scannet200_val.ckpt` Mask3D on the original complete Replica mesh, followed by original threshold.02 and NMS.1. This is a reproducible local baseline, not an exact replay of missing paper-supplied proposal assets. The full original mesh XYZ/index/RGB is verified; Open3DIS half-sampled masks/superpoints are excluded.

Original Replica mesh faces are quads. An isolated fan-triangulated copy retains every original vertex/index for the ScanNet graph segmentator0.01/min20. Original XYZ/RGB are never resampled; missing vertex normals are computed from triangles. This adapter is necessary for the superpoint-based Full frontend. Original mesh and GT files remain unchanged.

Baseline uses the original Replica YAML: frequency1, visibility tolerance.4, top40 views, one voted class per raw proposal, no output threshold. The repository's original `run_evaluation.py` defaults to uniform evaluation scores; that result is the official-config baseline row. A separately reported native-confidence row uses the same predictions with their computed confidences. No historical BPR, SAM-fused or class-specific filters are enabled.

Semantic AP/AP50/AP25 uses the original Replica evaluator:48-class macro average, IoU.50:.05:.90 plus.25, strict IoU comparison and100-point minimum. Actual output class-agnostic AP deduplicates only already-selected valid foreground members by exact point-set equality and keeps their maximum selected confidence. GT valid classes are collapsed to object identity, preserving small/ignore rules. No full-pool geometry score, GT-derived selection or budget refill is used.

K800 is the production Full budget. The original Replica baseline emits one class per raw geometry and therefore fewer members; it is not silently expanded to800. This comparison tests the complete frozen transfer configurations, not an isolated attribution to a single module.

Preserved failures: direct quad input caused the ScanNet segmentator to abort; the initial script and log are retained. The direct API call to the dense exporter initially lacked helpers that its CLI imports lazily; the empty failed directory and log are retained, and the adapter binds exactly those original helpers. Neither failure produced an AP result.
