## 1. 固定任务，只改变一个输入通道

|项目|A|B|
|---|---|---|
|修复对象|同一个原N/T父及其冻结父目标|与A逐候选相同|
|基础输入|原64维几何/六帧证据＋同一冻结128维mask_features_head|与A逐点相同|
|额外一维query输入|全零|非GT选定query在各原点的软概率|
|监督、未知/忽略掩码、损失|一份共同生成并封存的父目标监督|直接复用同一份，不重新配对|
|网络、初始化、训练与输出|同一193维输入/64隐藏宽/两轮8邻接网络|同结构、同参数量、同种子/预算|

同一父目标沿用当前最佳有效父GT配对及稳定性定义（命中≥20点、父纯度≥.6）。它由父本身确定，GT仅在规定训练监督和后置评测中读取，与query身份和A/B臂无关。当前task不把query当作需分割的目标提示，而是可能错误的辅助观测；B必须学会结合原父条件使用或忽略它。query错配、歧义、缺失不能导致B单独换target、重标unknown、屏蔽点或删除样本。

监督复用修正全点三态定义：稳定父的目标点target，其他已标注实例other，未标注点unknown；身份不确定父全unknown。unknown是当前三态CE的弃权类别，不混称“忽略标签”；已知域Dice仍排除unknown。任何无效点/忽略掩码均在臂分支前统一确定，A/B逐点一致。复用corrected_loss：父内other代价3、全点CE、已知域Dice .5、原高质量父保持 .25；不同时更换损失或重加权。

使用同一P1正确XYZ位置接口下的冻结Mask3D，父query由完整场景soft-IoU非GT top1选择，稳定query ID处理并列。query不跨场景/P0/P1继承ID。B新增的是**一维sigmoid软概率**，不加解码embedding、query类别、质量/资格头、区域图输入或新损失。A/B的head特征完全相同；本轮只测额外query概率的增量。

域、原点图、父成员先验、0.15米halo、原GD10最多六帧、≥2姿态组可见编辑门及min100回退一致。固定生成阈值沿用当前局部模型.8；已有区域平均基线保留其原预定.5诊断读出，不重选阈值，明确两者执行口径差异。训练用标签不成为推理筛父或选query的依据。

## 2. 小样本阶段：先确认学得会且使用了query

只在原fit96中取样；优先复用已诊断12场景的原父、输入与P1资产，不访问selection16/calibration24/holdout24。该阶段是训练样本能力检查，不是泛化评估。

建议预算16个不同父：每来源N/T各3个补点样本、3个删除样本、2个好父负例；同一父只占一个名额，完整halo点每轮出现一次，不复制稀少纠错点。按好父→删除→补点优先去重，在各类按固定hash排序。补/删样本可同时有另一类机会，分别记账。好父负例应同时记录其残余可修点，不能强称完美父；保持/误编辑按原父GT衡量。

样本类型允许用fit内共同训练监督及GT可行机会判定：补点要求可见域实际有目标补点机会，删除要求可见域实际有已知污染删除机会，并核对min100规则；好父要求原IoU≥.90。**不按P1探针成功、B预期优势、最终四个正例或query与GT是否一致来抽样。** 机会/好父类别不进入模型。样本数不足则报告覆盖缺口，冻结前调整数量并说明；冻结后不按结果补选。

当前12场景可供池只读统计：N稳定父39、补点机会14、删除机会13、好父25；T为33/29/7/3。类别重叠，这些不是最终16名单，也不保证排重后足量。执行时先检查完整共同标签与点域，再封存名单、query、采样hash与输入/源码身份。

预算拟定：共同种子20261014、相同候选顺序/初始化、AdamW(.001,.0001)、clip5、batch4、固定64轮、全域损失，A/B各一套模型。最终固定第64轮作为能力判断；逐轮训练曲线保留，只作机制诊断，不事后选择最佳几何轮数。这些数值在开始训练前写入独立contract，不能按看到的A/B效果改变。此预算尚未执行。

冻结A/B模型后，以相同父目标和执行规则读出：A、B、B_zero、B_shuffle。B_zero仅将额外概率通道置零；B_shuffle只在同一父halo内随机置换该概率，保留概率分布而破坏点对应，原64/128通道及所有标签不动。采用预先固定的3个hash种子，报告每个置换及均值，不挑不利置换。干预不重新训练，不换父query、不换GT目标、不调输出门。

必须检查query实际进入forward且置零/置换后输入确实变化；不能用模型有该通道或训练loss下降代替因果证据。置零/打乱属于输入干预，可能有分布变化；只能作为依赖证据，不能单独证明部署收益或整个先验的必要性。

小样本交付需逐父、按N/T、补/删/好父记录：预测前后IoU、正确补点/删除、误补邻居/误删目标、unknown编辑、好父尾部、实际点集、完整NT池和全部干预。训练分类/损失另表，不替代动作效果。

## 3. 小样本停止与继续条件

至少同时确认以下机制才支持继续：B相对A存在实际同目标纠错改善，不能只改善CE；补/删分别有正确动作证据而非全部弃权；误补、误删、好父损害和unknown未用总体平均掩盖。query置零或打乱后，该改善应明显减弱，且变化能在同一父的实际点集上定位。证据应分布在多个训练父，并分别报告N/T；不以一个池正例宣布成功。

若训练样本也没有有效改善、B未优于A、只学会更多错误动作或完全忽略query，就停止扩量，回查共同监督、损失、父成员先验、条件使用路径和执行门的影响。若B更好但干预不影响，记录“query新增价值尚未归因”，不自动扩大。不得按失败效果追改本轮标签、损失或阈值；需要修改时另立对照并保留失败模型。

训练内父IoU改善但完整NT没有新增价值，单列**冗余改善**，不能算几何池成功。小样本若提供安全纠错机制但池证据不足，最多支持下一内部评估的假设，不能据此宣布改进N+T或AP。

本文件不将95%身份准确率或任何旧诊断标准升级为永久硬门。正式继续判据、分母与支持数量必须随小样本contract在训练前锁定；如果结果只能说明部分机制，不以“通过”模糊带过。
