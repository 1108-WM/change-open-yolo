## 当前研究：FI1 split-grow family（v2三组消融已实现）

这是本项目拟议的改编方案，借鉴Clutt3R-Seg层次线索、SGS-3D分裂生长和GeoOpen3D几何／深度约束，不是三篇论文的完整复现。

“父”是可能欠分割、包含多个对象的粗区域；“子”是由独立实例种子生长合并得到的实例假设。现有merged区域可作首版父区域入口，但不能把旧U/U′局部删点别名直接当作实例层次。split、grow、merge分别记录关系，生长后的点集不必仍是严格父子包含。

1. **逐帧层次提示：** 核查像素级containment后才建立包含边；partial只作为重叠提示。保留叶节点、残余和父回退身份，不能将近似超点包含直接称为论文的二维mask tree。
2. **空间分裂：** 在粗父区域内，按superpoint邻接、连通性／密度生成多个seed；检查点数、空间连通和跨视角支持。该步骤用于区分对象，不只取轨迹支持位图的严格子集。
3. **受约束生长：** 只吸收邻接superpoint，结合几何连续性、深度边界、颜色或已有冻结视觉特征及点集重叠；拒绝明显跨界和seed冲突。新增特征缺失时先明确可用性，不能假定已有完整DINO资产。
4. **跨视角渐进合并：** 先高重叠且证据一致的proposal，后较宽松匹配；每步重算边界和视角支持，保留合并前点集与谱系供回退。
5. **family内选择：** 对一个family选择parent或一组可信grown children，之后仍按B分数进行全场景800个语义成员选择。800不是800个几何。parent+children全部拼接只作诊断臂，选择规则必须在看评测GT前冻结。

每个新点集都需要自身YOLO-World和Alpha-CLIP证据，不能继承父类别、分数或embedding；对同一新候选池重算6维同类竞争特征。层次选择与同类竞争排序可以并存，但不能用GT决定推理时保留谁。

1. **先定义实例假设关系，再决定跨来源竞争。** 同物体的替代范围、互补碎片、明确独立对象与unknown应分别记录；不重叠且特征相似不足以成为敌对关系。先用GT外逐视角局部支持、连接区域、原始分离证据和谱系评估关系，避免只靠小区域包含，也不把共同粗mask直接当成同物体。明确分离关系才进入排斥／竞争；unknown保留为未决假设，不能继续按相似根数量硬拒绝所有补全。保留成对关系与原始根，防止传递归并吞掉对象；不能以本轮GT标签建立实例组。
2. **把局部边界检查保留为约束，检验互补碎片归并。** 当前局部检查只能拦截部分跨界，不能独自证明同物体。继续核查各根与连接区域的多视角支持，区别同物体互补与两个相似且接触的物体；明确分离对否决、合并前候选与回退保留。先构造相同物体不重叠碎片、同类不同物体相接、粗mask共同覆盖、竞争根缺失等行为例，再冻结具体关系规则；不通过统一加硬门槛或取消全部保护修补负结果。
3. **下一轮关系规则仍按固定批次比较完整池。** 本轮另一3场景已完成且已读GT，不再称未见样本。轨迹mask入口为主，native／track／union／refined为原池对照；规则／取样／参数先冻结再诊断，原3与另一3继续分报，新的训练样本另按主场景固定取样。检查完整池净新增和被误拒的正确补全，不能只看剩余动作纯度或候选数量。SGS共同出现过滤尚未单独验证，不能因hierarchy_safe而认为已覆盖；Geo同框多mask机制须另立需要新SAM输出的任务，不能伪造备选。
4. **自身语义诊断已完成，下一轮需把择优输出纳入冻结方案。** 首版没有通过当前训练6 AP比较，不重复运行或按小批AP扫门槛。联合检验完整池净新增、正确类别生成、K800落选、较差同物体假设高分与原候选分数变化；不得只要求最终覆盖不降。新来源四个历史标志为0，冻结B存在分布风险，但尚未隔离该因素的因果。规则与参数先冻结，两批分报；训练内诊断不能替代开发集门控。
