# 实例关系与父可编辑性解耦：独立版本协议

用户授权实质调整任务，停止在旧A/C概率上搜索删除规则。保持同N/T、最多96原区域、GD10原最多六帧、原外层0训练范围112/24/24物理分割。该留出历史已评测，不称盲测；这次参数训练仍不得读其标签。A仅复用已封存最终点集，C新增局部证据不启用、不视为默认有效。新目录隔离，不修改旧合同/模型/预测。

关系任务：完整区域GT标识分布与六个GT-free固定参考点集(边界、保留父、4竞争实例)分布的随机点对same/different/unknown比例。已标注ID>=1000，包括评测范围外标识，均能提供关系监督；不使用父的可编辑性、有效类别名单或强制目标身份筛掉这些监督。区域混合/参考混合保持比例；真正未标注比例单独unknown，空参考不进损失。不存在“父不编辑→全部点关系未知”的共用标签。

关系表示：复用旧96个空间点token和原冻结观测；57维几何/RGB/法向/观测，位置按点集中心归一，去掉父成员/角色直接身份捷径。局部图2轮消息，各点集内邻接；shared48宽编码，sum/abs/product对称关系和实际最近边界点对，六个参考分别输出3概率。这个新版本同时改变任务与适配表示，不能声称唯一贡献来自拆一个开关。没有新C、SAM/DINO或整体GVC。

父任务：独立128点(父64+竞争各16)图读取原64维特征、空间关系与固定16统计，五分类edit/keep/out_of_scope/unannotated/ambiguous。原GT稳定目标规则>=20命中/纯度>=.6；稳定有效父若96可改范围存在已知污染且理想删除保留>=100点则edit，否则keep；其他父按原范围/未标注/含糊分开。标签只用训练监督、校准和后置评测，推理只用父模型预测。父模型不输入关系模型预测，两模型/损失/优化器独立，不需要将训练内高拟合预测再交给父模型学习。

训练112：所有区域每轮一次、有效参考各一次，无放回、训练类别权重median/count截断.2..10和父/场景平衡；关系24轮batch256，父60轮batch32，seed20261013(父+1)，AdamW .001/decay.0001，clip5，最后checkpoint固定。不给新模型旧A/C输出、GT错误名单或GT提议上界。

推理区域score=min(保留父参考p(different),4竞争参考最大p(same))。仅当父p(edit)通过及区域score通过才可联合删除；没有safe块头、收益回归或多个额外语义接受开关。GT-free union去重，重叠点取所选区域最大的same-parent预测检查，风险上限由1-score_threshold导出、没有独立调参，保留>=100点。只有异父证据、没有正竞争归属时弃权。

新校准16条规则：p(edit)=[.5,.7,.9,.95]，score=[.7,.8,.9,.95]。同旧几何安全约束：至少3动作/2场景，正确污染/全部删除>=.9，目标损失<=.01，未知<=.1，好父(.9)退化>.02比例<=.02，漂移0。合格规则按已知污染最多/少目标误删/未知/更严格threshold，全部不合格则弃权；只用24校准集。A/C旧规则与概率不再调参。原始两模型概率在读取校准GT前封存，真实点集再封存后读留出GT评测。

单独验收关系：same/different在p>=.9时，GT纯关系(.95)精度各>=.95，并各至少100对/10父/5物理场景。软比例crossentropy/MAE对训练常数，PR分参考/范围单列，不能当实例AP。父状态macroF1/混淆、edit精度及跨场景支持另列。三项不相互替代。

几何比较封存A/新D：去重后的污染正确删除/目标误删/稳定父标注未知/身份未知(范围外、未标注、含糊)分开；父提升/退化/好父尾部/漂移、完整NT池>=.02及>.5/.75/.78/.9/.95/.98新增覆盖。GT纯区联合仅后置诊断，不选动作。实际安全价值门仍需>=1池级增量和至少2动作场景并满足上述精度/风险；单个信号不证明有效。

若跨场景关系高精度仍未成立，停止这套从头训练小模块配方；下一方法需要实例分割先验或提供新边界信息。若关系成立而实际几何未成立，分别定位父判断、联合执行和区域机会，不能否定关系学习或直接接SL。两种情况本轮都不追加旧阈值/开关或自动扩大五折。允许未来局部重分割同时增删，不将纯删除当整个几何研究永久准入条件；前序补点已有少量池价值但整体安全尚未成立。旧骨干/SL/生产不改，GPU串行保留50GiB。
