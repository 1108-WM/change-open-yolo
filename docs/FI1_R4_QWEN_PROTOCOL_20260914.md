# R4：R2＋Qwen 独立证据对照（首次推理前协议）

本协议替代 09-13 尚未具备路由、预算和行为审计的草案；不覆盖旧文档和历史 Qwen 产物。R3b 分层分析及本轮行为审计通过后启动，主比较为 **R2 对 R2＋Qwen**，R3b 仅为已完成参照。模型、阈值或路由不依据这次分层 AP 调整。

## 实验问题与输出

检验 Qwen 的有限二选一证据能否改善固定 R2 输出的类别分数分配。R2 full200 模型、全部 600 条已选中几何—类别成员、点集、别名及列表顺序均固定。不补类、不删类、不重新应用预算、不训练新头。

当 Qwen 双顺序都支持另一类时，交换**同一几何两个现有类别成员**的 R2 数值分数。每个几何的分数多重集保持不变。明确这是分数重新分配，不能写成“完全不修改分数”；不会用 Qwen 自报置信度、文本概率或额外融合系数作为 AP 分数。其余类别成员原分不变。本轮是有限候选证据对照，不是独立开放词汇识别或最终全系统模型。

## 无 GT 路由及预算

- 数据：固定 55 扫描开发验证和 5 扫描重叠诊断；都使用已训练好的 R2 full200 预测。本轮没有训练扫描的 Qwen 推理；200 扫描训练划分不变。
- 对每个已选中几何，current 为 R2 最高分的已选中类别；同分按原生别名优先、类别索引升序。proposed 为冻结自身 Alpha 完整 198 类 cosine 的 argmax，同分按类别索引升序。
- 只有 Alpha 可用、两类别不同、proposed 也已在 R2 top600 中且其分数严格低于 current 时才是可行动冲突。Alpha 首选在预算外时记录并跳过，不改成局部次优类。
- 视觉请求来自本轮 `yolo_views_v1/ncs_validation60`，逐几何点集 SHA256 与绑定几何核对。按可见比例降序、数字帧号升序选 3 个不同帧；使用已冻结 scale_index=0 的自身 crop。缺 3 个有效视角时记录跳过。
- 在满足上述条件的冲突中，按 current R2 分数降序、几何 key 升序，每扫描最多 4 个。全 60 扫描最多 240 几何、480 次推理；未用完预算不跨扫描补齐，不依据类别 AP 选候选。所有跳过原因和未路由候选都记账。
- 55 开发验证与 5 诊断分别汇总。开发验证不是盲测，诊断与训练主场景重叠；不读取 val312，不称整系统 OOF。

## 模型和回答合同

使用本地 `pretrained/checkpoints/Qwen2.5-VL-7B-Instruct`，在准备阶段绑定全部模型、tokenizer、processor 文件的 SHA256，不凭目录名声称远端 revision 已验证。环境 `.venvs/qwen25vl_py311`；bfloat16、CUDA、SDPA、eval/inference_mode，seed=20260914。processor min_pixels=100352、max_pixels=200704（每图上限），3 图/调用；max_new_tokens=8、do_sample=False。

两次调用使用完全相同的 3 张裁剪；第一次 A=current/B=proposed，第二次 A=proposed/B=current。提示词全文冻结于 `tools/fi1_r4_qwen_core.py:prompt` 并绑定代码哈希。仅去首尾空白后严格接受 `A`、`B`、`ABSTAIN`，不解析包含解释、额外类别或多个答案的文本。AB=B 且 BA=A 才交换分数；AB=A 且 BA=B 表示保持。无效、拒答、顺序不一致、裁剪/运行异常均保持原分并报告原因。每个顺序最多尝试一次，失败不追加提示或重试。

每次调用保存原始文本、输入 token 数、生成 token 数、耗时和运行错误，逐顺序落盘。冒烟取完整路由清单的第一个任务；通过后续跑同一任务清单，已成功落盘的顺序不再次调用。不基于冒烟语义答案调整合同。读图前及运行结束核对 RGB 内容哈希和裁剪尺寸，禁止静默复用旧实验回答。

## 审计与评测

准备/推理入口禁止读取 GT、训练标签、R3 模型/分数或 AP 文件；文件访问保护记录违规。评测为单独入口，复用项目原 ScanNet200 实例评测器（198 前景类，至少 100 点，AP 的 IoU=0.50:0.05:0.90，另报 AP50/AP25，严格大于阈值）。不误写成包含 0.95 的 AP50:95。

运行前行为测试覆盖：双顺序语义映射、解析失败/拒答回退、相同分数、预算外替代类、重复任务、缺失/多余输出、越界裁剪、有限预算和分数多重集不变。另用不调用动作应用函数的实现逐行复建输出，核对全部 60 扫描成员、类别、分数与交换账本；R2 AP 必须重放历史值。报告候选覆盖、跳过/拒答/一致性/运行失败率、实际交换数、逐类与 55/5 AP，以及像素和调用成本。阴性结果完整保留，不扩预算寻优。
