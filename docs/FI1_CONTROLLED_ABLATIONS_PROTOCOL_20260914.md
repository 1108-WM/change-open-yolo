# 固定R3b条件下的训练量与第一点信息对照（2026-09-14）

用户授权先分析开发55→val312差异及第一点信息使用情况，然后分开验证训练量与几何质量／父子变化特征。本协议在新模型拟合及新AP前固定。属于看过历史验证结果后的开发实验，不称盲测，不覆盖原R3b结果。

## 共同固定项

共同底座为冻结R3b：D-v3同一official100七模型与原上游点集、自身YOLO/Alpha证据、R1预算前成员、原26列顺序、竞争IoU目标、扫描→几何→类别权重、HGB全部参数（100轮、深度3、7叶等）、float64排序、每扫描600预算及同分规则。Qwen均关闭，不裁类别或来源，不加NMS。

只重训下游评分头。训练与评测点集不重建，不把验证标签用于特征或拟合。先完成所有预测及独立重训／排序核验，再独立计算55和312 AP。诊断5不用于结论。现有验证集已用于开发，本轮结果也只解释为开发证据。

B重新拟合，必须逐扫描、全部预算前分数与原冻结R3b一致，并重放两组原AP，否则停止。四组各另拟合一个独立估计器，对全部367个评测扫描逐成员比较分数。保留全部组结果；Q、P给出单因素对照，QP只描述两类信息共同加入及条件差异，不把两个收益相加。

**Q的三个字段：** 本几何各已核实质量记录的均值、极差、缺失指示。Legacy对应A阶段`deployment_unified_quality`；实际追加的细化点集对应C阶段`corrected_oof_temporary_refined_quality`。后者沿用旧字段名但本批来自冻结部署模型，不能称OOF预测。每条记录必须核对场景、实际点集摘要及数量；细化质量不得借用父候选质量。同一点集含多个来源质量记录时按固定均值／极差汇总，不按GT或新AP挑选。完整D-v3 `challenger_score`是B/D阶段排序产物，本轮不把它冒充纯质量特征。

**P的四个字段：** `log1p(父几何数)`、平均父子IoU、平均新增点占子点集比例、平均删除点占父点集比例。父关系来自B阶段明确的并集与native/track父关系，及C阶段细化的原并集父关系；统一映射到去重后的实际点集，排除自身与重复父链接。交并集从points.npz独立计算，不读取语义／实例标签。无父关系填零，不用相邻但非父关系的几何替代。

既有A/C质量模型使用official100监督，训练侧不具有整系统折外性。本次保持上游不变以隔离新增特征，但显式暴露监督质量可能带来训练侧偏乐观；即使验证有收益，也不能声称上游泄漏风险已消除。若要严格整链OOF，应另建上游按主场景重训的实验，不与本轮混称。
