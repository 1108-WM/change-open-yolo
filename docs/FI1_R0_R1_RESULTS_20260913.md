# R0/R1 首轮开发验证结果（2026-09-13）

新R0/R1已在55个开发验证扫描上完成首轮同底座对照；R1直接扩类未取得收益。5个与训练主场景重叠的扫描单独评测，不合并为60扫描验证结果。训练开发池仍为official100＋NCS-train100的200扫描，内部按139主场景分组；其全量自身视觉证据尚在补齐，R2/R3/R4尚未完成。

## 固定设置

详见 [R0/R1共同协议](FI1_R0_R1_PROTOCOL_20260913.md)。同一轮D-v3冻结七模型生成的几何、同一套每个几何自身的YOLO/Alpha证据、同一直接分数、去重和600条场景预算。R0保留原生已有多类及非原生已有类；R1仅扩大具有非原生别名的几何的类别集合，共同成员分数完全一致。

YOLO使用每10帧采样、每几何最多40个可见视角的完整198类标签票数分布；Alpha最多20视角、SAM ViT-B、3尺度、完整198类余弦，固定softmax尺度100，两种有效分布等权平均。没有几何分数相乘、SMS删除、top1折叠或Qwen。精确同分依次按原生已有别名优先、几何SHA256、类别编号排序。

验证来源的5,887个历史点集全部找到视角/裁剪一致的Alpha证据，并核对模型与特征哈希、重算聚合和完整余弦；15个新增点集的299视角完成GPU补算。两个候选组使用完全相同的最终证据。历史Alpha没有当时RGB字节哈希，固定历史证据复用不等同重新运行视觉模型。
