# 候选条件局部修复能力检查（首批）

目标：在训练局部分割前判断输入范围、可见性与操作粒度是否有超过完整NT池的机会。停止旧框正点重提示/保守裁剪规则叠加；不降低旧门槛，不训练SL。

固定开发200内上一轮已非GT哈希选定的10场景、80父候选，原物理五折×旧90/新110，40N/40T，不替换锚失败候选。不从旧GT诊断补选机会样本。此为首批能力检查，不代表开发200全量。

在GT前定义三种范围：旧父内.15m边界且排除旧core（只删）；完整父候选（只删）；父候选及距离父点<.15m的原场景邻域（可增删）。后两种没有受保护共有核心。2cm原坐标体素与原始超点作操作粒度对照，不扫描半径或体素参数。

枚举磁盘上RGB、深度、pose的完整交集，先封存有效pose、.1m/15度物理分组与全部帧清单。按原WORLD_2_CAM的深度内参缩放/截断规则逐帧投影，可靠证据必须测量深度>0、相机z>0且差<=.02m。既统计至少1组，也统计至少2组；与旧30帧用同一全帧组号对照。未知、缺测、遮挡区域保留。全部帧读取，无GT视角排名。只投影后置GT确定的理想修复错误点以节省计算；这不构成推理观测获取算法。

GT仅在候选、范围、帧清单封存后读取白名单10场景，父目标按最佳有效GT IoU确定、同值按GT ID升序，无有效交集单列。评测目标>=100点且在原有效类别中。理想点修复保留范围外父点、范围内按该目标GT修正，<100点时保留最少父污染使其满足评测最小值。报告父级增益和完整NT池级增益、≥.02连续改善、严格>.50/.75/.80/.85/.90/.95跨档，不能只看新增>.75。

整超点/体素理论最优按固定真实点和污染点计算IoU分式的精确上界；允许单元在可改范围边界裁断，因而是乐观上界，不能当真实整超点可执行动作。最优点数<100另列。统计同单元目标/有效其他实例混合，不将未知标签都称相邻实例。

独立复核旧21可靠锚污染漏斗，同时列“全部非目标”和“有效其他实例”口径，区分两组可见、mask有效、带边距排除、正支持否决；旧两个视角区域下无预算污染理想删除同时计算整个父和旧边界两个口径，避免混淆。所有点数按候选累计。

冻结现有11份B26/五折L/归一化资产，原NT保持。能力诊断没有预测点集、自身语义、SL扩池、K800输出或实例AP，也没有训练。下一阶段按结果决定范围、观测与点/体素表示，随后才检查原物理场景五折外局部归属学习。Mask3D/Graph Cut只作方法参考，不证明本项目收益。
