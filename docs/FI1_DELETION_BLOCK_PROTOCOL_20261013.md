# 固定GD10局部删除块实验（训练前冻结）

2026-10-13，开发200原物理五折、1599父N/T、原0.15米点域、冻结GD10最多6帧和逐点64维特征。只删除，不补点、不改轨迹/SAM/DINO/SL；保留完整NT。

主要问题：同一个模型已经提出的删除中，是否可学出有益的局部块？重点测试封存B的原始概率提议（先按两组可见且p(other)>=.8形成块，再判最低100点），同时检查修正监督的新生成器G。封存C的实际纯删除作旧门对照。

G沿用50179参数原逐点网络/强父先验/12轮，仅改监督：所有点一次进入完整域损失，没有分层重复采样；父内其他实例CE代价最多3倍，Dice和好父保持用完整域。原最佳有效GT目标只有父纯度>=.6才作为确定身份；其他候选逐点全未知，无目标Dice纠错、无好父保持。GT只用于训练监督，推理不会读纯度/资格。

每个外层f，四个原训练折各轮流内留出：生成器在其余三个折120场景训练、对内留出40场景产生提议；共20个内层生成器。再用四折160场景训练5个外层G，仅预测外留出40场景。验证器仅读当前外层160场景的内交叉提议与监督，绝不混用旧全局OOF提议作训练。封存B外折模型未看当前外折GT，可以作为验证器推理输入；但与内层G的提议分布不同，此迁移限制必须明确报告。G上的配对结果用于检查同配方转移。

拆块严格复用独立审计的无向冻结8近邻连通分量；没有GT拆块、超点决策或额外体素约束。可见性门先执行，最低100点在所有已选块联合删除后检查，不足则回退。

输入为块、图邻接到的父内保留点、剩余父候选、4个固定竞争候选的独立区域描述。每区64维逐点特征+3类提议概率的均值/标准差、空间范围、点数、可见率与存在标记，共140维。S：展平七区域的MLP；R：共享区域编码+块与其余区域的成对关系网络，均值/最大值聚合关系。R是SSTNet/CliqueNet式区域关系的简化对照，不复现语义树或完整论文，也不增加骨干。

每个实际块的监督：正确删除已标注其他实例比例、误删父目标比例、未知比例及实际父IoU变化；不稳定父全未知、拒绝纠错。安全标签仅稳定身份、块全为已知其他实例且真实删除IoU增量>0。40固定轮，父候选/场景等权，正负权重只从该外层训练数据估计、最多5倍；每轮每块一次、不复制少量删除样本。损失BCE安全+2倍比例MSE+0.5倍IoU后果SmoothL1。固定p(safe)>=.9选块，没有外折门限扫描或候选理想可修开关。后果回归作为监督与诊断，不能称分类概率已校准。

实际输出：B_raw、C_gate、G_raw、B_summary、B_relation、G_summary、G_relation；NT为共同基线。预测全部封存后才评测GT：父/完整NT增量、多IoU档、污染/误删/未知、好父尾部、漂移、重复、N/T及场景折。GT纯块筛选仅后置诊断，绝不混为预测。

成功沿原保守几何门，且首次>=1目标获得纯删除池IoU增量>=.02；动作减少或精度提高不够。主要结论看B_relation能否从封存B选出真实池价值，G对照不能替代。训练内实际精度、尾部与后果拟合也报告，不以高召回替代可靠性。通过几何后另立自身语义/SL协议，本轮无AP。
