# 旧版正收益 DM-SMS-1 val312 准备修复：冻结批次重放解释补充条款

状态：`frozen_before_nogt_replay`

日期：2026-08-24

## 1. 原始批次不可改写

train100 和 validation60 的旧 Qwen `batch_outputs.jsonl` 是冻结历史产物，其中受新增非空文字验证影响的记录仍保存原来的 `valid=true`。准备修复不得把旧文件中的 `valid`、决定或汇总原地改写。

因此，用新验证器直接审查旧批次时，预期会准确报告：

- train100：2 条旧“有效”记录不再满足新结构合同；
- validation60：1 条旧“有效”记录不再满足新结构合同。

这些是预注册的修复命中，不是新重放过程的意外错误。

## 2. 正式重放验收对象

正式验收使用新的独立安全决定目录：

1. 从旧原始文字重新解析全部任务；
2. 满足新结构合同的记录重新计算旧版双顺序决定；
3. 不满足新结构合同的固定记录安全保持原类别；
4. 新双候选账本由独立审计器检查，要求 `audit_valid=true`、`error_count=0`；
5. 新完整账本由独立审计器检查，要求 `audit_valid=true`、`error_count=0`。

主预注册第 6 节中的“新批次重放审计错误数为 0”，以新的安全决定重放及其独立账本审计为准，不要求不可修改的历史批次在新增合同下继续维持零发现。

## 3. 停止条件

如果新验证器命中的任务集合不是主预注册固定的 2 条 train100 和 1 条 validation60，或者新安全账本审计出现任何错误，立即停止，不进入 val312 预注册。
