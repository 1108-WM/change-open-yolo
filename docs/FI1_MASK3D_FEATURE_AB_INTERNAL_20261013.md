# 冻结Mask3D逐点实例特征：局部增删A/B开发对照

本轮只改变新增128维Mask3D mask_features_head特征是否启用。A/B使用同一个192输入、64隐藏宽度、两轮8邻接消息的CandidateLocalSegmenter；A新增通道在标准化后置零，B启用。无CliqueNet、竞争/质量/资格新头、新帧或SL/AP。旧模型、合同和预测保持。

固定原外层0训练160的112/24/24物理场景身份，N/T父、完整父+.15米域和原GD10最多6帧。从112按非GT物理场景哈希取16模型选择、其余96拟合；不重新随机分原校准/留出。只训练A/B两套参数，不在112上另行重训。相同初始化、候选顺序、AdamW(.001,.0001)、clip5、最多24轮；每轮一次完整候选全点域，无稀少纠错点重复。复用修正监督：原冻结最佳有效目标配对且>=20命中/父纯度>=.6才有target/other监督，其他父全unknown；未标注点unknown。污染CE代价3、完整已知域Dice .5、原高质量父保持 .25。复用96区仅作诊断，输出不受区域/体素整块约束。

Mask3D冻结现有scannet200_val.ckpt，eval/no_grad。安全输入适配仅切片原processed列0:9，网络使用XYZ与RGB，不访问superpoint/语义/实例列；2cm量化、颜色标准化和稀疏索引遵循当前包装器。不改变现有权重/Mask3D forward。用只读forward hook捕获mask_features_head输出128维，按稀疏坐标显式对齐输入体素，再用inverse_map回到原点。现有包装器raw_coordinates实参为归一化颜色，本轮遵循其调用约定、不同时修正该历史接口；point2segment=None避免使用原GT分段。导出前后固定随机状态，全部场景pred_logits/pred_masks及包装器硬mask/分数需逐值一致。该一致性针对同一GT-free无分段输入的前后调用，不声称等于历史使用原segs的N。保存原点映射、局部联合ROI特征、两次输出哈希和权重/代码身份；先过接口核验再训练。输入列污损不影响适配、同体素不同原点仍可独立预测须有测试。
