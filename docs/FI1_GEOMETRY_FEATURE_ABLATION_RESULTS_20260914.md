# 固定200训练：几何质量／父子变化特征对照结果（2026-09-14）

**B/Q/P/QP四组训练、独立重训、全部367扫描预测及55/312完整AP均已完成。扩量组缺少新增数据，未实施。** 原R3b历史产物保持不变。

## 固定设置与结果

训练仍为official100＋NCS-train100，共200扫描；开发55与val312不进入拟合。四组共享D-v3几何、R1预算前类别成员、竞争监督、样本权重、HGB参数及600预算。无新视觉推理、无Qwen、无NMS或来源过滤。下列均为开放词汇三维实例分割AP，按百分数显示。

| 组 | 特征 | 开发55 AP / AP50 / AP25 | val312 AP / AP50 / AP25 | 相对B：开发 / 312 AP变化pp |
|---|---|---:|---:|---:|
| B | 原R3b 26维复现 | 38.624395 / 46.861528 / 51.654812 | 27.573541 / 38.317402 / 43.942346 | +0.000000 / +0.000000 |
| Q | 26＋3维自身几何质量 | 39.584435 / 46.688005 / 51.281908 | 28.208731 / 38.415701 / 43.349514 | +0.960040 / +0.635189 |
| P | 26＋4维父子点集变化 | 38.624395 / 46.861528 / 51.654812 | 27.573541 / 38.317402 / 43.942346 | +0.000000 / +0.000000 |
| QP | 26＋以上7维 | 39.584435 / 46.688005 / 51.281908 | 28.208731 / 38.415701 / 43.349514 | +0.960040 / +0.635189 |

**结论：质量特征带来小幅主AP收益，父子变化在本配置下没有额外收益。** Q相对B的开发AP变化+0.960040pp，312变化+0.635189pp；312 AP50变化+0.098300pp，AP25变化-0.592832pp，不能称所有指标均改善。

加入质量后55→312的AP差距仍为11.375704pp（原11.050854pp），没有缩小。说明当前遗漏质量信息可改善评分，但不足以解释或消除跨集合差距；数据量因素因缺资产仍未验证，不把未完成实验归为负结果。

Q仅使用本点集A/C质量的均值、极差与缺失标志；P使用父数、父子IoU及新增／删除点比例。未将B/D排序分数冒充质量，未把父候选质量赋给子候选。定义见[协议](FI1_CONTROLLED_ABLATIONS_PROTOCOL_20260914.md)。

**父子特征实际未被本轮评分树选用。** P新增4列在全部树中分裂次数为0；Q和QP均只使用新增的自身质量均值（108次分裂），质量极差与缺失标志未参与分裂。全部367扫描中，B/P及Q/QP的入选成员与排序分别一致，分数差仅为浮点量级。该结论限定于当前固定特征表达、目标及树容量，不等于父子信息永远无用。

新增字段并非准备失败或全部为零：训练19,931几何中3,187个有父关系，开发55中866个、312中8,038个；三组自身质量缺失均为0。训练四个父子字段分别具有3、3,185、3,077、109个不同取值。

## 可解释范围

质量模型仍来自使用official100监督的固定上游部署包，尤其C字段虽保留oof旧名称，本批并非折外预测。新增显式质量特征可能暴露训练侧乐观估计；本轮保持上游一致，但不等于消除整系统训练依赖。

开发55、val312均已用于项目开发，不称盲测。该实验只比较同一200训练上的特征变化，不能证明扩大训练量的效果，也不能证明最优组合具有统计显著性。312 GT沿用已核对NPY标签编码及PLY点序的绑定文本，未从原始annotations独立重建。
