## 2. 必须纠正的旧建议

精读文件主体形成于 2026-08-20 前后，旧首选是“替代类双支持 + 原类双强反证”。后来 v2.2 的 7006 个任务产生 0 次换类，这条路线已经试过，不能再建议机械收紧门槛。

笔记 §17.2 从 OpenTrack3D 推出了“只能在冻结的两个候选中仲裁”，这个限制不是该论文的方法：原文让 MLLM 在完整给定类别表里识别。旧两类以外可能有正确评测类，新增独立识别分支应允许它提供这类证据。

“属性必须禁止一切类别词”“AB/BA 是所有新接口的必要条件”也只适用于旧仲裁合同。位置偏置研究支持检测候选顺序敏感性，不证明每一种视觉识别任务都必须采用二选一双重否定。

原文确有使用 Top-1 的工作，例如 OpenTrack3D；Details Matter 同时报告 Top-1 与 Top-K。借鉴视觉头不要求改成本项目每个 mask 最终只输出一个类别。识别器的一条类别建议可以增加一个独立证据字段，同时保留其他语义假设。

## 4. 第一优先级：FI1 几何指导二维目标证据

工作树 `tools/fi1_full_alpha_adapter.py` 中，`make_views` 用可见投影点计算框，`export_alpha` 调用 `predictor.predict(box=...)`，按 SAM 自报 predicted IoU 选一个 mask。Alpha 的第四通道是这个 SAM mask。

因此实际链路是：

```text
FI1 三维点集 → 可见投影点 → 二维包围框 → SAM 新掩码 → Alpha 编码
```

三维细化改变了点集，不保证改变包围框；相同框、相同图像可能返回相同 SAM mask。框发生变化也不保证 SAM 的目标归属正确。SAM 自报 IoU 描述其二维掩码预测质量，不等于它选中了当前三维实例。

这不意味着几何改善必须让 Alpha 换类别或提高 cosine 才能产生 AP 收益。若父子类别本来就正确，保留同样的语义证据也合理；此时关键是更优三维 mask 是否保留、是否在同类竞争中排到前面，以及是否带来新的阈值覆盖。目标区域对照用于检验目标混淆和类别证据问题，不能替代质量排序的验证。

建议新增以下可独立检验的环节：

1. 记录可见投影点落在 SAM mask 内的比例、跨视角对应关系与二维目标有效像素；重复投影的三维点应另存唯一像素统计，避免把采样密度误认为面积。
2. 外溢只在有深度/点对应证据的位置计算；没有投影点的像素属于未知，不能都当成背景。
3. 比较纯框提示与“框 + 对象内部正点”提示。正点按空间覆盖和可见性选取；两源共同区域只是支持证据，不是正确性真值。负点必须有可靠的其他对象归属或几何证据，不能把 FI1 删除区全部默认成负点。
4. 保持最终三维 mask 不变，只改变语义编码所用二维目标，比较完整类向量及最终同预算 AP。这样能区分几何改善本身与视觉接口的贡献。

这是借鉴对象区域建模后提出的本项目扩展，不冒充 Details Matter 在 ScanNet200 上采用的原配方；其附录明确该数据集用框提示，点提示用于 S3DIS。

旧 v3.2 已有 22 个几何的 parent/refined/core/removed 区域对照，不需要再从零开发区域集合。但那条区域分支是投影 alpha、固定共同 crop 的诊断配方，尚未统一为当前全来源完整多尺度 Alpha 主证据；不能混用两条分支的绝对相似度。

## 5. 第二优先级：有辨识信息的视角融合

目前前 20 帧按可见点数排序；同一个几何内它等价于按可见率排序。聚合权重为可见率，这保证覆盖，但未显式考虑：

- 目标在实际模型输入中有多大、是否能看见类别判别部件；
- 多帧是否只是重复的相近视角；
- SAM 是否跟随了错误邻物；
- 同一类别支持是否只由某一个异常视角推动。

尤其是删掉难以看到的点之后，可见率可能增大，但这不证明几何更完整或语义更正确。

可以先使用已保存的逐视角特征，计算可见率与一致性、尺度敏感性、有效目标面积等信息，比较原聚合与固定的质量感知聚合。在设计上避免用“当前最高类别置信”单独决定视角权重，否则可能强化一个稳定的错误类别。相机位置不同也不保证看到不同对象表面；应结合视向及覆盖集合。

当前 36 维只保存总体有效视角比例、均值和逐类视角/尺度标准差，尚无 SAM/投影一致性、目标面积和视角冗余特征。标准差混合了视角与尺度变化，后续可以分别诊断，不立即把大标准差作为硬拒绝条件。

## 6. 第三优先级：把 Qwen 的识别能力用于补充语义证据

旧 `finite_candidate_classes` 只保留 canonical 类和 Alpha 第一类；属性提示禁止类别词，随后 AB/BA 在这两个类中判断。假设两类都错误，Qwen 再强也无法通过合法输出补出第三个正确评测类。

OpenTrack3D 的实际提示是让模型辨认红框物体并返回完整类别表中的类名或 none。视角按对象点云落入相机视锥的比例排序、面积作平局判据；这不等于本项目带深度可见性检测的完全相同配方，也不能把它解释成已证明“相机距离越远越好”。

建议先固定 Qwen2.5-VL-7B、图像和词表，新增独立识别接口，输出合法 class ID 或 unknown 与简短视角依据。先不提供旧类别和 Alpha 第一名作为答案暗示。它的单类建议只表示该源支持一个类，没有被选中的其他类是未提供支持，不自动构成反证。

之后把建议、跨视角支持和缺失状态送入共享逐类评分；不把自报 confidence 或 token 概率直接解释成 AP 分数。首先检查相对于 YOLO/Alpha 的正确类新增覆盖、错误补充和类别混淆，再核对相同输出预算下的 AP；不能只报告与两个旧答案的 agreement。

上下文分支单独比较。当前本来就有全景+crop；新增全景开关不构成新方法。轮廓可能标错，红框也有成功论文支持，须以受控实验选择。AttrSeg 的属性思想适合提供可见轮子/抽屉/部件等短证据，但用途和相邻物只作补充，不根据“办公室里”推断一定是 office chair。

## 7. 排序、SMS 与当前样本的边界

目标评分仍应为每个 `(geometry, class)` 产生分数，其输入包括原标签图、bbox、Alpha、可选 Qwen、独立几何质量及同类竞争关系。Qwen/Alpha 负责类别证据，几何质量和重复关系负责定位与竞争信息；这些变量可能相关，不预设独立后直接相乘。

Details Matter SMS 用全场景唯一 proposal 的类内均值/标准差衡量相对相似度，再过滤 proposal。本项目历史硬 SMS 已有负结果，不优先重复阈值扫描。若将标准化相似度作为连续逐类特征，这是新假设，不能称为复现其删除策略。

当前 2283 个几何是代表样本的一跳上下文，**不是 92 场景的完整 proposal population**。不能用这个偏置子集的均值/标准差冒充论文 SMS 的全场景统计。现在的同类重叠特征是局部竞争证据，与全场景 z-score 也不是同一个量。

同理，333 个代表几何适合机制诊断，47×198 或333×198并不产生同数量的独立训练实例。最终 AP 比较需要固定完整场景的输出合同，不能把代表样本 AP 当完整系统 AP。基础证据对照、增加几何质量、增加局部竞争必须分开；上游隔离仍按现有排除集合实际重建，不直接使用旧 OOF。

## 8. 建议的执行顺序

1. 完成当前冻结导出和审计，作为完整 Alpha/原标签图基础对照；利用缓存计算视角质量和三维到二维目标一致性的诊断。
2. 在已有固定代表样本上预先定义“纯框 vs FI1 支持提示”的配对对照，固定三维 mask、模型、视角和输出预算；衡量是否改善目标归属和正确类覆盖。
3. 新增同模型、同图像条件下的 Qwen 完整词表识别证据对照，与区域/视角改动分别消融；未知不删除旧假设。
4. 在监督上游排除通过后，训练逐类质量/竞争评分，最后比较完整场景、同预算的实例 AP、head/common/tail 和重复错误。已有强控制不变，新增固定全局 K 实验另命名，不冒充历史 append-only B2。

反幻觉和不确定性论文主要用于约束这些接口：区分未知与反证，检查顺序/视角不一致，报告覆盖率与错误率，避免长推理或过度否定。这些是可靠性设计依据，无法单独证明三维分割 AP 会提高。

当前最有研究价值的组合是：**用 FI1 的点集、来源和视角关系构造目标证据，再做多源、逐类且考虑几何质量与同类竞争的评分。** 它能够分别检验几何信息是否进入视觉表示、语义证据是否新增正确类、以及正确预测是否排到前面。是否超过当前基线仍需要上述实验验证。
