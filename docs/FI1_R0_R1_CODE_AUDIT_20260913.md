评测器原先核对回执中的点集路径，却可能读取另一条 binding 路径。已加入路径一致性检查，并补全预测—证据—视角—几何身份链接。实际60扫描没有发生路径错配；加强检查后重新重建 GT 并评测，55验证和5诊断的 R0/R1 共12项 AP 数值与首轮完全相等。该 AP 重跑沿用原 ScanNet 评测器，不是第二份 AP 实现。
