# 论文阅读记录：当前方法依据与后续路线

更新日期：2026-08-11

本文件已合并旧的“新论文建议”和原始论文清单，只保留对当前第一创新点、第二创新点及未来候选形成有直接价值的结论。实验事实以 `CURRENT_EXPERIMENT_STATUS.md` 为准。

## 一、当前研究问题

当前工作分为两个互相解耦的创新点：

1. **风险感知的多视图轨迹候选安全接入与关系几何补全**：解决类别无关候选形成、跨来源竞争和关系补全。
2. **几何节点上的多视图开放词汇证据聚合与类别相关竞争**：在几何冻结后解决完整类别分布、可靠性、类别赋值和同类重复排序。

论文的作用是提供问题定义、可观测证据和安全决策原则，不等于完整复现。任何参数都不能从 safety60/even48 反向选择。

## 二、第一创新点的主要论文依据

### OpenMask3D 与 Open-YOLO 3D

- 共同原则：类别无关 3D proposal 与开放词汇语义应分层。
- 当前采用：保留 Open-YOLO 3D 的 Mask3D + YOLO-World 主干，把创新放在候选形成、安全接入和后续多视图语义。
- 限制：原始 MVPDist/top-1 语义不能解决重复候选、跨来源分数不可比和类别相关竞争。

### Details Matter for Indoor OV-3DIS

- 关键思想：独立二维观测提升到 superpoint；只在共同可见区域计算帧级 sIoU；轨迹内做多视图共识，随后进行候选合并、细化和竞争。
- 当前采用：hierarchy-safe 同帧处理、共同可见 sIoU 关联、多视图 superpoint 共识、D2b/F2 候选链。
- 不照搬：不恢复其硬阈值删除、直接包含清理或完整分类体系；本项目结果已证明单独轨迹形成不是开放词汇 AP 解法。

### GVC-Seg

- 关键思想：用深度一致、多视图二维—三维对应关系估计候选质量，缓解不同 proposal 来源的原始分数尺度偏差。
- 当前采用：GVC 作为候选质量、关系和风险模型的连续特征。
- 不照搬：GVC 分数不能直接替换最终 AP 分数，也不迁移论文阈值。直接 `score=q` 已在本项目失败。

### IoU-Net、Quality Focal Loss、VarifocalNet

- 共同启示：分类置信度和定位质量应分开建模；高质量稀有正例需要区别于普通正负样本。
- 当前采用：独立质量 `q`、三状态收益／无变化／伤害建模、轨迹伤害 focal 头。
- 不照搬：二维框 IoU、类别×质量联合分数不等同于三维候选对全局 AP 的边际作用。

### SelectiveNet、Deep Gamblers、Conformal Risk Control

- 共同启示：不可靠动作应允许拒绝并回退；应报告风险—覆盖率而不只看 AUC。
- 当前采用：native 回退、共存/no-op、未通过门槛的 pair-intersection 不物化。
- 限制：当前场景和正例数不足以宣称严格分布无关风险保证；过度拒绝会得到近零覆盖。

### Rank & Sort Loss、AP-Loss

- 共同启示：最终目标是高分端顺序和 AP，不是单独分类准确率。
- 当前采用：official100 五折 AP 方向、一次性全局 AP 和高置信动作风险共同作为门槛。
- 后续边界：动作跨组件后的 AP 非加性，暂不直接训练全局 AP-Loss；只有更多独立 official 场景后才考虑场景级排序损失。

### Focal Loss 与 Class-Balanced Loss

- 当前价值：轨迹有益保留和 pair 补全正例极少，需要减轻易负样本支配。
- 当前采用：轨迹伤害抑制和 pair-union threshold-cross 使用固定 focal 思想。
- 限制：同场景、同目标样本高度相关，不能把关系条数当独立样本数；有害动作也不能仅当普通负例。

### Deep Sets 与 Set Transformer

- 关键思想：重叠组件是无序、可变长度集合。
- 当前采用：最小值、均值、最大值等低容量排列不变统计。
- 暂不采用高容量集合网络：official100 组件数量仍小，容易记忆场景结构；只有数据规模扩大并证明手工统计欠拟合后再比较。

## 三、第二创新点的直接论文依据

### MVPDist／Open-YOLO 3D

- 适合作为快速多视图语义基线。
- 下一步不再只保存 top-1，而是保留候选×视角×200 类的完整分布、margin、entropy、可见性和冲突。
- 形成轨迹的视角与独立验证视角分开统计，避免循环自证。

### Alpha-CLIP

- 对象 mask 条件下的视觉—语言特征可减少背景干扰，适合作为 YOLO-World 的独立语义源。
- 当前只计划对象中心 crop 与有限上下文 crop 的多视图分布，不允许固定阈值直接重分类。
- 只有 Z1 完成并确认冲突类型后才执行；它不替代几何候选形成。

### SAS

- 可迁移思想：不同二维／语义模型的证据需要先对齐和校准，再按可靠性融合；不应对每个实例做粗糙三选一。
- 当前适配：记录 YOLO-World、Alpha-CLIP 的完整分布与模型间 agreement，使用保守融合或 abstain。
- 不采用其蒸馏训练和额外二维模型主干。

### OE3DIS 与 OpenMask3D

- 支持“先固定类别无关 proposal，再在可见多视图聚合 mask-aware 视觉 token”的顺序。
- 当前第二点必须在 geometry node 上聚合语义，不能让单帧 top-1 反向硬决定实例几何。

### MPEC

- 关键启示：开放词汇语义不仅要类别可分，也要同类实例可分。
- 当前适配：记录候选内跨视图一致性、相邻候选间类别分布可分性和同类重复风险，用于 Z4 组件内竞争。
- 不迁移其三维编码器训练和伪实体对比学习。

### GVC-Seg 的语义侧

- 投影可见性、二维 mask 支持和语义分布应共同决定候选可靠度。
- 当前第二点将几何质量与语义可靠性分层使用：几何质量不直接输出类别，类别分布不直接修改 mask。

### OV3D-CG 与多模态大模型

- 上下文可帮助长尾、功能描述和低置信冲突。
- 当前只保留为后期少量冲突候选的 router，不在第一轮下载或接入 Qwen-VL/LLaVA，也不让 MLLM 参与全量候选形成。

## 四、未来几何候选方向的储备

这些论文不属于当前 Z0–Z4 执行清单，仅在第二点完成后或发现固定几何上界不足时重新评估。

### MV3DIS

- 有价值的顺序：稳定三维锚点 → 深度一致的独立二维观测 → 多视图 affinity → 可回退局部边界变体。
- 当前旧 A/B/unknown owner 空间全局 oracle 仅 `+0.067988 AP`，因此不恢复旧动作；未来必须定义新的、更大 oracle 空间。

### VoxelFlow 与 SGS-3D

- 共同启示：从可靠核心受约束生长，或先拆含混区域再生长，比直接 union/intersection 更合理。
- 当前限制：候选接受器和独立验证不足，不允许据此恢复硬删点或硬生长。

### SAMPro3D

- 可迁移思想：从可靠三维核心选择提示点，投影到高可见、视角独立的帧重新请求二维证据。
- 本项目已做的 SAMPro3D/medoid 分支未形成可推进系统，当前终止；未来若重开，必须是新的 action/oracle 合同，不复用已失败阈值。

### MaskClustering

- 可借鉴全局多视图共识率作为连续关联证据。
- 不能用它替代候选质量判断；当前残差节点质量不足，直接图聚类已不适合作为主线。

### SA3DIP、Superpoint Graph、OVSeg3R

- 共同启示：原子 superpoint 的边界决定后续合并上限；二维实例边界可用于剪除有证据的跨实例图边。
- 当前 IBSp 没有形成稳定增益，不再重新分割现有底座。未来若更换原子层，必须先证明粒度与边界覆盖优于当前 ScanNet superpoint。

### FoundObj、EvObj、GrabS、ASSIST-3D、SpaCeFormer 等

- FoundObj 的对象内部一致性／边界 cut 可作连续物体性特征。
- EvObj、GrabS、ASSIST-3D、SpaCeFormer、UniSeg3D 等依赖重训、强化学习、合成场景或大规模端到端数据，不符合当前轻量改造边界。
- ClickSeg3D 需要人工点击；ShelfGaussian 面向 3D Gaussian；均不进入当前官方全自动评测主线。

## 五、当前论文到代码的优先级

```text
立即：Z0 分类—排序 oracle 分解
  -> MVPDist/Open-YOLO、OpenMask3D 的几何—语义分层

随后：Z1 完整 YOLO-World 多视图分布
  -> 记录可见性、mask 支持、top-k、margin、entropy、冲突

再后：Z2/Z3 Alpha-CLIP 与训练自由融合
  -> 参考 Alpha-CLIP、SAS、GVC-Seg；只做预注册规则

主创新实现：Z4 exact geometry 类别聚合与组件内类别相关竞争
  -> 参考 MPEC 的实例可分性和 SelectiveNet 的拒绝/no-op

最后：若固定几何上界仍不足，再定义新的语义辅助几何动作空间
  -> 参考 MV3DIS、VoxelFlow、SGS-3D、SAMPro3D
```

## 六、不可跨越的边界

- 不把论文中的二维框 IoU、NMS 阈值或数据集参数直接迁移到三维 mask。
- 不因 safety60 一次结果修改损失、阈值、融合权重或候选动作。
- 不把 GT-only oracle 输出写回推理账本。
- 不把完整软类别分布压成 top-1 后再做几何硬门控。
- 不因为论文方法有效就忽略本项目已经完成的失败实验和候选回退合同。
