### 2. 三篇论文原始方法的准确含义

**Clutt3R-Seg：真正的父子关系存在，但发生在每个二维帧的 mask tree 中。**

- 根节点是较大的 object-cluster，通常解释为欠分割；
- 中间节点是 object，可能是正确物体 mask；
- 叶节点是更小的 sub-object，通常解释为过分割；
- 子节点必须在像素层面被父节点包含；
- 每条 root-to-leaf 路径最多允许一个 proper segment；
- 跨帧分组只把叶节点放入 leaf graph，边只连接不同帧的节点；
- 先按 super-voxel 加权空间 Jaccard 分组，再按 Duoduo-CLIP 语义相似度分组；
- 残余叶节点只有在父节点其他后代也都是残余时，才进行 conditional parent substitution；
- 最终是分组后的实例，父节点和所有子节点不会作为固定预算中的重复 proposal 同时保留。

因此，Clutt3R-Seg 的父节点主要是层次化误差解释和回退节点，不是我们当前意义上的“完整 3D 父候选”。

**SGS-3D：核心是 split-then-grow，不是父子树。**

- 先把点云划分为 superpoints；
- 对每个经过共现过滤的 3D semantic mask 使用 HDBSCAN，按空间连续性拆成 semantic-geometric seeds；
- 从 seed 出发，用特征相似度与 3D 点集重叠构成 affinity，逐步吸收邻近 superpoints；
- 单视角生长后的 proposal 再进行跨视角 progressive merging，先高重叠合并，后逐步放宽；
- 原始 semantic mask 是中间输入，seed 和 grown proposal 是中间/最终候选，论文没有把原始父 mask 与所有子 mask 一起送入固定预算排序。

**GeoOpen3D：支持几何约束，不支持父子实例树。**

- 通过投影、super-sampling 和深度增强构造几何保持的 RGB-D；
- 使用 GroundingDINO 生成语言引导的区域框；
- 使用 SAM 产生候选 mask；
- 通过 mask 内深度一致性和边界深度梯度选择 mask；
- 回投到 3D 点并进行 mask merging；
- 任务主要是开放词汇语义分割，不是层次化实例 proposal 生成。

### 3. 对当前父子实现的最终判定

当前 \`stable_regions\` / \`exclusive_siblings\` 是我们自行设计的无 GT 改编，不是三篇论文中的原始算法。它使用已有轨迹、同帧 containment/partial 关系、至少两个位姿组的 superpoint 支持来从父点集选择严格子集；之后保留父候选，并把父子几何同时重新获取 YOLO/Alpha 证据，放入 B/K=800 竞争。

当前实现与论文方法有四个关键差异：

1. 没有建立 Clutt3R-Seg 式逐帧 mask tree，也没有 one-proper-per-path 约束；
2. 没有 SGS-3D 的空间连续性分裂、feature-guided growing 和渐进跨视角合并；
3. \`partial\` 关系可能只是不同实例的重叠，不能单独证明父子实例关系；
4. 父子同时进入固定预算会制造包含、近重复和大规模排序替换。

这与已有结果一致：30 场景几何池诊断显示子集可以增加候选覆盖，但 5 场景真实 AP 中 stable 版本比 parent-only 下降约 0.0322 个百分点，exclusive 版本没有形成有效 family。该结果首先说明当前候选族合同有问题，不能直接否定 split-then-grow 或层次线索。

### 4. 2026-10-01机制复核：原公式与项目表示的边界

再次对照[SGS-3D v2全文](https://arxiv.org/html/2509.05144v2)与[官方仓库](https://github.com/wangchaolei7/SGS-3D)：本次可见主分支仍仅README，不能借作者代码消除细节歧义。SGS的输入是共现过滤后的逐视角mask；当前项目使用传感器深度可见性、置信度／稳定度和hierarchy_safe，且初版候选受merged父区域／谱系限制，这些不能称为SGS原流程。

SGS式(5)明确写特征余弦乘3D点集IoU。项目将点簇提前变成互不重叠的完整超点种子后，种子与未分配邻接超点的点集IoU恒为0；原论文的部分点集种子可能不同，不能据此断言论文算法无法生长。现有代码因而采用“特征×观测覆盖”，这是已注明的改编，不能改名为原公式复现。单视角正支持可以解除跨视角启动门槛，但如果仍要求每个新增超点在来源mask内有覆盖，它就不能补到来源mask完全未覆盖的超点；空间／特征如何为这种区域提供可靠归属仍需独立验证。论文没有规定我们的父区域完整替换、两机位分离证据或同帧所有种子永不重新合并规则。

GeoOpen3D正式PDF第5页式(7)包含绝对值：mask内深度相对均值的平均绝对偏差；TXT抽取漏掉绝对值竖线，不能按有符号差求和实现。式(8)是边界深度梯度范数的正和，式(9)以正权重最小化，但正文又称其鼓励边界对齐几何边缘；边界项方向存在需要核查的解释歧义，不能静默反号或将简单梯度惩罚称为已验证的原算法。当前GD缓存`gd_multimask_output=False`，没有同一框的多个SAM候选，无法直接验证原文的候选能量选择。项目的mesh接触深度跳变约束仅是迁移探针；户外语义分割设定也不能直接等同ScanNet200实例AP。

上述区别不构成否定SGS-3D／GeoOpen3D的证据，也不构成转向Clutt3R-Seg的依据。工程机制小批结果与回执只在当前状态维护。

## 1. 当前研究问题

项目当前不是单纯提高类别无关 mask AP，而是同时处理两个相互独立的问题：

1. 几何层：是否得到完整、少碎片、少重复的 3D 实例 mask；
2. 语义层：同一实例是否保留足够的开放词汇类别假设，并用正确的逐类别分数排序。

完整 val312 已表明 FI1-D-v3 的类别无关几何有效，但FI1-D-v3冻结单类控制及DM-SMS-1的开放词汇AP低于论文基线；Legacy历史联合25.4155不属于这条单类流程。代码确认原有语义预测列被压缩成 top-1，并使用几何排序分数；它们是覆盖与逐类排序损失的具体机制。现有实验同时改变了多项因素，尚不能将全部AP差距定量归因于top-1或某个模型。

因此当前论文阅读必须服务于以下结构：

```text
唯一几何层
  └── 多个独立语义假设
      ├── YOLO-World 类别与逐类分数
      ├── Alpha-CLIP 对象视觉证据
      ├── 来源与几何质量
      └── 选择性多模态大模型验证
```

## 2. 最直接的方法依据

### 2.1 Open-YOLO 3D

核心价值是用 YOLO-World 的多视图二维检测为高质量 3D mask 提供快速开放词汇语义。它证明语义头不必全部依赖昂贵的 3D 视觉语言编码器。

对当前项目最重要的不是最终 top-1，而是其预测表示：同一 3D 实例可从多视图检测得到多个类别成员及各自分数。ScanNet200 论文基线为 `24.7/31.7/36.2` AP/AP50/AP25，说明完整多语义预测本身是强控制。

当前迁移结论：

- B0 必须完整保留 OpenYOLO3D 已有预测列、类别和分数；
- 几何去重不等于语义去重，同一个 mask 对应多个类别是合法的；
- 不能先把多个语义成员压成 top-1，再期待 Alpha-CLIP 或 Qwen 恢复丢失的类别覆盖；
- 新语义模块应校准每个类别假设，而不是把整组假设改成一个标签。

### 2.2 OpenMask3D

OpenMask3D 支持“类别无关 proposal 与开放词汇分类分离”的基本架构：先获得 3D mask，再选择可见视角，以 mask-aware 图像特征和文本相似度分类。

当前迁移结论：

- 几何层应有稳定身份，视觉证据按几何复用；
- mask-aware crop 比整幅图像更能减少背景干扰；
- 多视图聚合应保存分布、一致性和视角质量，而不只输出最终类；
- 语义层可以迭代升级，不应反向改写已经冻结的 mask。

### 2.3 Details Matter for Indoor OV-3DIS

这篇论文是当前最重要的工程与语义配方依据。它把二维/三维候选、超点级跟踪、重叠清理、迭代合并、Alpha-CLIP 和标准化最大相似度过滤组合成完整系统。

与当前项目直接相关的结论：

- 2D mask 可能覆盖多个物体，需要处理包含、重叠和重复；
- 超点级逐帧匹配比让错误累计 mask 持续传播更稳；
- Alpha-CLIP 通过对象 alpha mask 抑制背景，适合作为 YOLO-World 之外的独立证据；
- 论文使用高可见候选视角、多个 crop scale 聚合，而不是只看单帧单 crop；
- SMS 的作用是基于场景内最大语义相似度的标准化可靠度过滤，不等同于随意改类；
- 单标签与多标签评测差距很大，进一步说明保留多个语义假设的重要性。

论文报告的参考结果包括：ScanNet200 2D+3D 单标签 `25.8/32.5/36.2`，多标签 `32.7/41.4/45.3`；类别无关 2D+3D 为 `46.6/59.0/64.4`。项目中的 Mask3D native 类别无关 AP 更高，因此当前优先补语义表示，而不是照搬整套几何。

### 2.4 Alpha-CLIP

Alpha-CLIP 在 RGB 之外接收 alpha mask，使图像编码更集中于目标对象，适合处理 crop 中背景、邻物和遮挡干扰。

当前使用原则：

- 每个唯一几何的视觉 embedding 只需计算一次；
- 同一 embedding 可以与多个类别文本假设计算相似度；
- 保留多视图/多尺度相似度、聚合值、margin、entropy 和缺失状态；
- Alpha 分数是语义证据，不是 mask 几何分数；
- 不能用 Alpha top-1 覆盖 YOLO-World 全部分布；应在 B1 做 OOF 校准或可靠度融合。

### 2.5 SAS

SAS 的可迁移思想是：不同视觉语言模型的输出需要先对齐和校准，再按可靠性融合，而不是粗糙地对每个实例做模型三选一。

当前只借鉴以下部分：

- YOLO-World 与 Alpha-CLIP 保持独立；
- 比较模型间 agreement、margin、entropy 和冲突类型；
- 允许保守融合或 abstain；
- 不迁移其完整蒸馏训练和额外二维主干。

### 2.6 MPEC

MPEC 强调开放词汇表示既要类别可分，也要同类实例可分。对本项目而言，这提示语义相同不代表几何可以合并，几何相同也不代表只能保留一个类别。

当前迁移为：记录跨视图一致性、相邻候选的类别分布差异和同类重复风险，用于候选竞争和审计；不直接迁移其三维编码器训练或伪实体对比学习。

## 3. 多模态大模型与上下文路线

### 3.1 OV3D-CG

OV3D-CG 用多模态大模型结合场景上下文、位置、邻近物体和功能线索解决语义歧义，并选择更适合观察目标的视角。其启示是 MLLM 更适合处理“仅看 crop 难以判断”的长尾或功能性类别。

当前迁移原则：

- 简单、高置信实例仍由 YOLO-World/Alpha-CLIP 处理；
- 只有冲突大、潜在 AP 价值高且视角有效的候选进入 Qwen；
- Qwen 输出作为某些语义假设的验证证据，不强制把实例压为一个类别；
- 不让自由文本直接越过类别映射、置信校准和审计边界。

### 3.2 OpenTrack3D

OpenTrack3D 结合视觉与空间跟踪多视角候选，并为每个 3D 实例选择少量信息量高的视角交给多模态大模型。它证明 MLLM 不需要处理所有帧。

2026-09-09核对 [v3原文](https://arxiv.org/html/2512.03532v3)（2026-05-14）：明确采用 **Top-1**，使用Qwen3-VL-4B，ScanNet200选3个视角，以全图红框在完整给定词表中直接识别并允许none。表4分类头消融CLIP22.9→MLLM26.0 AP。我们的旧Qwen2.5属性+两候选AB/BA并非相同任务；应先用现有模型比较独立识别证据，而非直接换模型或压缩最终多语义输出。

对当前路线的价值：

- 视角选择可以显著控制 Qwen 成本；
- DINO/mask-aware 视觉一致性可以辅助识别错误跟踪；
- 语义只应参与有限的跟踪或复核约束，不能不加审计地改写几何；
- 其 ScanNet200 `26.0/37.7/45.4` 说明选择性强语义头有潜力，但项目当前应先完成 B0/B1/B2 表示修复。

### 3.3 OV3D-CG、PoVo 与 vocabulary-free 设定

PoVo 用视觉语言助手从场景图像自动发现词表，再用 Grounded-SAM 定位并聚合 3D 实例。它的核心价值是从固定候选词表扩展到自动词表发现，而不是当前 AP 修复的直接模块。

后续若扩展 vocabulary-free：先由 MLLM 提议场景词表，再由快速二维模型定位；但评测类映射、同义词和幻觉必须独立审计。当前阶段不引入，以免混淆多语义基线恢复。

## 4. 质量校准与选择性预测依据

### 4.1 GVC-Seg

GVC-Seg 强调投影可见性、二维支持和几何—视觉一致性共同决定候选可靠度。当前适合把这些量作为独立特征保存，但必须区分：

- 几何质量：mask 是否完整、稳定、重复；
- 语义可靠度：某类别假设是否可信；
- 排序分数：该类别预测在 evaluator 中的相对顺序。

三者可以联合校准，但不能互相直接替换。

### 4.2 IoU-Net、Quality Focal Loss 与 VarifocalNet

这些工作共同说明分类置信度与定位质量常常错位，可以预测 IoU/质量并用于排序校准。对本项目的启示是 FI1 几何分数可以作为输入特征或单独报告，但不应直接成为开放词汇类别分数。

### 4.3 SelectiveNet、Deep Gamblers 与风险控制

这些方法支持“无法可靠判断时 abstain/路由”的设计。当前可用于 Qwen router：只有预计收益大于风险的歧义候选调用昂贵模型，其他候选保留 B1 分布。

### 4.4 AP-Loss、Rank & Sort Loss、Focal/Class-Balanced Loss

AP 是逐类别排序指标，训练目标若只优化候选级平均正确率，可能牺牲长尾类别或某一 fold。B1 fold 4 的负迁移应从类别频率、来源、逐类排序和校准漂移诊断，而不是只看整体 accuracy/AUC。

当前不立即更换损失；先保持 B1 的 OOF 合同，通过逐折、head/common/tail 和类别级误差确认问题。若确需修改，应作为新的预注册消融。

## 5. 后备几何路线

这些论文用于未来几何扩展，不是当前 B0/B1/B2 的前置条件。

### 5.1 MV3DIS

MV3DIS 用粗 3D 分割反向指导多视图 2D mask 对齐，并加入深度一致性，减少独立 SAM mask 的跨视图碎片。适合未来作为“3D 锚点→2D 对齐→3D 细化”的类别无关候选模块。

当前 FI1-D-v3 已在 val312 证明几何改进；历史B2的42条refined计划经逐点审计只有22个相对B1真正新增的几何，因此暂不更换几何底座。

### 5.2 VoxelFlow 与 SGS-3D

共同启示是从可靠核心受约束生长，或先拆分含混区域再生长，比直接 union/intersection 更合理。未来只有在新动作空间证明有足够 oracle 上界时才重开，不能恢复已经失败的硬阈值生长。

### 5.3 SAMPro3D

可借鉴“从可靠三维核心选择提示点，再投影到高可见且相对独立的帧请求新二维证据”。它适合修复特定边界，不适合作为当前全量重新生成方案。

### 5.4 MaskClustering

全局多视图共识率适合作为连续关联证据，但不能替代实例质量判断。直接图聚类容易把早期错误传播到整个组件，必须保留局部回退和审计。

### 5.5 Group3D、OVSeg3R 与超点图路线

这些路线说明原子超点边界和语义兼容性决定后续合并上限。若未来重做几何，应先证明新原子层在边界覆盖和粒度上优于当前 ScanNet superpoint，而不是在现有节点上继续堆合并阈值。

### 5.6 SegDINO3D、DINO 与视觉一致性

DINO 特征适合提供跨视角对象一致性和错误合并提示，但它不是开放词汇类别概率。当前可作为视角质量、实例一致性或 router 特征，不能直接覆盖 YOLO/Alpha 类别分数。

## 6. 其他论文的保留定位

- SOLE：支持把对象级开放词汇语义与场景/关系上下文结合，适合作为后期上下文建模参考。
- Any3DIS：SAM2 式视频传播对时序一致候选有价值，但当前不替换已经冻结的 Mask3D/FI1 几何。
- DCSEG、Mosaic3D：提供跨模态密集对齐和开放词汇语义学习参考，通常需要训练，不属于当前轻量 OOF 校准主线。
- OVI-MAP：物体级视角选择和紧凑语义地图适合降低多视图编码/MLLM 成本。
- SpaCeFormer、CoSMo3D：空间关系、功能和部件位置有助于处理功能性查询，属于语义扩展而非当前 AP 恢复。
- FoundObj、EvObj、GrabS、ASSIST-3D：对象性、交互或强化学习思想可作长期储备，但依赖新的训练/数据合同。
- EmbodiedSAM、VGGT-Ω、Zoo3D、Clutt3R-Seg：面向具身、几何基础模型或更广场景泛化，暂不进入当前最小实验路线。

## 7. 论文到当前代码的固定映射

| 设计 | 主要论文依据 | 当前实现要求 |
|---|---|---|
| 类别无关几何与语义解耦 | OpenMask3D、Open-YOLO 3D | geometry identity 独立保存 |
| 同一 mask 多类别假设 | Open-YOLO 3D、Details Matter 多标签结果 | B0 完整保留预测列 |
| mask-aware 独立视觉证据 | Alpha-CLIP、OpenMask3D | geometry 只编码一次，支持多个文本类 |
| 多源校准而非覆盖 | SAS、GVC-Seg | B1 做 OOF 分数校准 |
| 新几何保守加入 | Details Matter、FI1-D-v3 | B2 append-only |
| 选择性上下文验证 | OV3D-CG、OpenTrack3D、SelectiveNet | Qwen 只处理高价值歧义 |
| 类别排序与质量分离 | IoU-Net、AP/Rank losses | geometry score 不替代 class score |

## 8. 当前研究结论与优先级

1. 首先复现并冻结 B0：完整多语义强基线，而不是 top-1 基线。
2. B1 保持候选和类别成员完全不变，只校准各语义假设；当前已有显著增益。
3. B2 只 append FI1 新几何；每个新几何必须建立独立多语义假设，不能继承一个父类别。
4. 先完成 v2 强审计与一次 official100 复跑，再分析 fold 4 和 B2 新几何评分。
5. Qwen 是后续有限预算的语义验证器，不是当前全量分类器。
6. val312 只用于方法冻结后的最终迁移，不用于阈值、prompt、视角或路由策略选择。

时间紧时只保留 B0、B1、B2 三组核心比较即可；额外模型/四组细分消融在论文写作需要时补充，不应阻塞当前主线。
