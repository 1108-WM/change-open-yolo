## Full 的唯一配置身份

**GD10 + official100 冻结 D-v3 七模型 + GD10 匹配 597 训练 B26 + N/T/U/U′ + K800。** 视觉模型冻结；597 训练的是当前成员评分 B26，生产 D-v3 没有替换成 597 重训版本。K800 是全场景最多 800 个“点集—类别成员”，不是 800 个不同物体。历史 validation312 类别 AP/AP50/AP25 为 29.230610% / 39.901908% / 45.578362%。

权威身份入口：`.local/fi1_core_ablation_val312_20261006_v1/contract.json`、`.local/fi1_g10_full597_closure_20260921_v1/inventory.json`、正式模型的 `B.json` 与 D-v3 `summary.json`。旧 A 前端的 `R3b_full597.joblib`、Q29、597 重训 D-v3 都不是此 Full 的默认权重。

```text
ScanNet/Replica RGB-D、相机、原点域及超点
 ├─ Mask3D 原生掩码 N ＋ YOLO-World 原生类别/检测缓存
 ├─ 固定验证帧身份（独立verification_frames.json）+ YOLO-SAM验证掩码
 └─ GroundingDINO + SAM，每 10 帧观测 GD10
      → 同帧 hierarchy_safe → 共同可见超点 sIoU 关联
      → 多视角共识 → 迭代合并 → 轨迹候选 T
N/T → 竞争/互重复处理 → GVC/关系特征 → 冻结 champion/唯一几何
    → D-v3 七模型 → N/T/并集 U/细化 U′ 实际点集
    → 各实际点集自身 YOLO 与 AlphaCLIP 证据
    → 冻结 R1 类别资格 → 20 维自身/来源 + 6 维同类竞争 X26
    → 冻结 B26 评分 → 固定排序 top800 → 预测封存
    → 原 ScanNet200 或 Replica 实例评测器 → 结果/展示
```

生产 R1 保持历史 native-only 不对称展开；当前有效 SL 的 S 已另行对称修正。U′ 是 U 的子集，不保证包含原父 T。新点集必须重新获取自身语义，不能继承父类别、父分数或不匹配的 Alpha 缓存。推理不读 GT；训练监督及封存后评测才读 GT。
