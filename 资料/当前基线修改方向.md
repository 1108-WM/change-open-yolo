## 第一创新点的冻结推理合同

### 1. exact geometry node

完全相同的 native 三维点掩码先归为同一几何节点。节点关系与质量统计只计算一次，避免同一几何的不同类别副本在类别无关组件里重复投票。此步骤不删除 native，不改类别、几何或原始分数。

### 2. 轨迹伤害抑制

对每条可控轨迹预测 `P(keep)`，固定分数公式为：

```text
track_score = full_quality_q * (1 - (1 - P(keep))^3)
```

它是连续惩罚，不设置 hard threshold，不删除候选。native 分数逐位保持原样。

### 3. pair-union 补全

对满足纯推理新颖性合同的轨迹—native 关系构造几何并集候选；只追加，不改已有候选。固定分数为：

```text
base_quality = min(track_quality_q, native_exact_group_median_quality_q)
append_score = base_quality * (1 - (1 - P(threshold_cross))^3)
```

重复 union 几何只保留 OOF `P(threshold_cross)` 最高的关系。没有阈值、指数或跨模块权重扫描。

pair-union 分类器以 50/50 类别平衡权重拟合；推理时必须先按 official100 组件平衡自然正例率 `0.047577720588447926` 做 prior correction，再进入上述 append-score 公式。原始 `predict_proba` 不可直接作为 `P(threshold_cross)`。

### 4. 训练与推理隔离

- official100：场景隔离五折 OOF；外折场景不参与本折训练或校准。
- 全量模型：只在策略冻结后用 official100 全量拟合。
- safety60：只可加载冻结模型、构建无 GT 特征、生成 plan 和运行一次内存 AP。
- 任何 GT 字段都不得写入 safety60 推理账本。

## 当前核心问题

类别无关候选已经提高，但 safety60 正式开放词汇 AP 从 native 的 `29.971029` 降到 native+F2 的 `29.820266`。因此当前瓶颈不是继续增加候选数量，而是：

1. 多视图语义只保留 top-1，完整类别概率、margin、entropy 和冲突被丢失；
2. native 与 track 的类别分数和几何质量分数不在同一尺度；
3. exact／near-exact geometry 上存在多个类别副本和跨来源同类重复；
4. 分类错误、排序错误、类别相关重复竞争的贡献尚未分解；
5. head 类下降而 tail 类上升，说明简单追加候选会破坏高频类别排序。

## 第二创新点的当前修改方向

建议主线：**几何节点上的多视图开放词汇证据校准与类别条件竞争**。

它不再修改第一点的候选几何，先把候选视为冻结 geometry node，再解决完整类别分布、跨来源可靠性、语义—几何联合排序和同类竞争。目标不是直接训练新的 200 类分类器，而是估计每个 `(geometry node, class)` 假设成为官方真阳性的概率。
