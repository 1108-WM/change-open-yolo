# 同一父目标query小样本A/B：未支持扩大训练

2026-10-14。**结论：共同修复任务学得会，但额外query软概率没有取得有效增益；按训练前锁定的条件停止，不开展场景隔离扩量。** 结果只覆盖训练样本，不是泛化、生产N+T或AP结果。

## 对照与封存

原fit96内复用诊断资产，按good→deletion→addition和固定hash选16个不同父，来自10个物理场景。N/T各2个好父负例、3个删除样本、3个补点样本；类别互斥占名额，但机会可以重叠，全部实际IoU≥.90的好父共7个。未按query准确性、诊断成功或B预期优势选样。共同可编辑域有1588目标补点机会、924污染删除机会；部分删除样本仅1—3点机会，删除量主要集中于N，不能视为均衡的大范围能力验收。

A/B均为193输入、64宽、两轮8邻接的CandidateLocalSegmenter，58435参数。共同输入原64维及P1冻结head128维；A最后一维为0，B为原父完整场景soft-IoU无GT top1 query的sigmoid概率。query错误不改变父GT目标。共同标签与原父最佳有效GT逐点核对；同一三态CE、未知类别、known Dice域、父内other代价3、Dice .5及原good保持 .25。两臂相同初始化、候选顺序、每轮全域、候选等权、AdamW(.001,.0001)、clip5、batch4、固定64轮（每臂256更新），仅最后一轮评测，无最佳轮选择。head归一化只用16父，共同clip±10；query不归一化。

父、0.15m halo、原六帧、成员logit先验、≥2姿态组编辑、.8动作阈值、min100回退均复用。区域平均固定旧P1 .5口径，仅作为诊断比较；与.8训练输出执行阈值不同，未调门限。没有新的损失、质量头、embedding、混合父拆分或观测。

输入/共同监督/名单/query/归一化/源码及数值判据先封存[contract](contract.json)；模型先封存[models_frozen](models_frozen.json)，GT-free概率及点集随后封存[predictions_frozen](predictions_frozen.json)，之后读取GT评测。B_zero及3个预注册种子B_shuffle仅改变query，无重训练。

## 预注册继续条件与query干预

训练前规定：B−A平均父IoU≥.01、至少3父优势≥.02、N/T平均优势均非负；补/删各≥20正确点且覆盖≥2父；补/删正确率≥.9、目标删除率≤.01、未知编辑率≤.1、好父最坏损失≤.02且相对A额外损失≤.005、无漂移；B_zero和3次shuffle均值的平均IoU下降各≥.005。全部成立才继续，池新增单列而不替代机制验收。

实际B−A均值为**−.000128**（−.0128个百分点），无父优势≥.02，N/T均略负。B−B_zero均值仅+.0000258；B−shuffle三次均值为−.000725，即打乱后略好。其余补删动作与保护条件通过。失败项及全部逐父差值见[decision](decision.json)，不追改门限或选更好训练轮。

干预确实生效：置零改变8/16父点集、共79个对称差点；shuffle三次分别改变11/8/9父，共106/104/100点。点概率平均绝对变化约.00448/.00485/.00497/.00503，最大单点变化达.709—.796。B输入层query列权重norm .4570，A该列 .3528；权重大小只证明计算路径存在，不证明有益使用。结论应为**query有影响但没有可归因的纠错收益**，不能称通道未接或完全忽略query。

## 停止后的原因核查

1. 已排除本轮A/B更换GT任务、标签错位、基础输入不一致及query漏接：独立核对同父标签、64/128逐值源输入、无GT full-scene top1及最终模型回放全部通过。
2. 共同任务确实学得会：A/B训练记录损失从约.904降到.0589/.0606；冻结模型eval模式共同损失为.05640/.05065（无dropout，不能与逐更新train均值混用）。B损失稍好却动作IoU稍差，说明三态全点损失与固定高置信动作不是同一个指标。补点1588机会中A/B分别1528/1498点argmax正确、1436/1423点达到.8；删除924机会中887/894点argmax正确、829/846点达到.8。执行门留下部分机会，但本轮不调阈值。
3. A已有head128和原父聚合，在这16个稳定父上能纠错；额外query概率可能与已有证据重复、未学到有用的点对应、或固定损失/融合方式不足以鼓励这种依赖。这些是解释假设，没有通过本轮区分。当前证据不支持直接扩大同一输入拼接训练，也不否定所有实例先验或其他融合方式。
4. 样本少、稳定父且训练拟合接近饱和，部分机会很小，均限制结论范围。混合父多目标拆分、跨场景收益和生产AP均未评估。后续如修改监督、融合或执行，应另立最小对照并保留本轮失败，不能在本轮追改结果。
