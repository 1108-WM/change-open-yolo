# 删除块实验独立审计与下一步

2026-10-13。原实验：`fi1_deletion_blocks_development200_20261013_v1`。本目录只新增审计、CPU推理与后置GT诊断；不修改原合同、模型、预测、报告、SL或生产配置，不启动新训练。

## 判断

原几何验收失败结论成立。点集和池级汇总可复现，原物理场景嵌套折的训练/预测名单符合隔离要求。主要问题不只是折外泛化：当前G在提议阶段丢掉大部分可用污染点；验证器只学到极少的小块，迁移到旧B的大量块；收益回归在训练集内也未胜过零预测，实际执行则完全不使用收益回归。

因此应先解决**有覆盖、同来源的局部区域提议与训练样本供给**，再检验归属判断。不建议立即再跑完整35模型训练、加大验证器、增加帧、调整SL或沿外折GT修改门限。

## 1. 提议供给损失比“训练测试块数不同”更根本

在**稳定身份父候选、相同现有六帧、至少两组可见**条件下，后置只删除已知其他实例点，未知标注点保留：

|可用删除集合|超过完整NT最佳IoU至少.02的目标|
|---|---:|
|全部可靠可见的已知污染点|70|
|仅B已经提议的点，再用GT逐点保留正确删除|8|
|仅B完整纯污染块|4|
|仅G已经提议的点，再用GT逐点保留正确删除|0|
|仅G完整纯污染块|0|

每种诊断均形成实际点集，遵循不足100点回退；这是可行GT筛查，不是学习结果，也不宣称求出了所有块组合的最优上界。70不与旧120/89直接比较：这里限定稳定身份、已知其他实例，不把未知标注算正确污染。

稳定父内有32620个可靠可见污染点。G实际阈值提议只包含260个，约0.80%；B包含7413个。G污染点p(other)中位数0.0351，90分位0.2448，而仍用0.8提议门。四个旧B有效见证父在G上全部0块。G真实目标点得分也降低，因此不能仅凭概率下降断言特征完全失效；它说明修改损失后，原0.8不再提供可用的提议召回。

后续只能筛选的验证器不能创造提议里缺失的点。严格两阶段的提议应承担覆盖职责，最终动作承担安全职责。不能把这一点理解成直接调低执行门；放宽/替换提议必须与最终执行分开，并只在外层训练内部选择设计参数。

315是五套验证器训练集块数之和，不是每个验证器都见过315块，也不等于315个独立父/场景。所有训练集都小于128的batch，因此40轮实际上每模型只有40次优化更新。摘要模型134149参数，关系模型46469参数。轮数本身不是拟合证明。

最大安全训练块仅29点，B测试的稳定纯块最大278点，完整B块最大4575点。scene0051_00/c003的主要有效纯块就是278点。小块并非无用，但现有训练不足以支撑跨尺度泛化。

不稳定父训练块合计只有21个，fold3为0。用这种G分布训练的验证器去判断B，不会因为G已经修正身份监督就自动安全弃权：B仍携带旧概率和旧身份监督影响。B_relation的不稳定父70次动作必须单独统计；同源G_relation仅4个不稳定父、共4点，不能把二者混成同一泛化失败。

## 3. “学习实际后果”尚未成为有效的后果判断

代码位置：`tools/fi1_deletion_block_core.py:74`定义真实动作标签；`:110`解码安全概率/三种点比例/IoU增量；`tools/run_fi1_deletion_blocks.py:252`执行时只读取第0列p(safe)>=.9。后果回归仅为辅助任务，未参与动作许可，也没有保证各输出一致。

复算结果（块级统计在最终min100回退之前）：

- B_relation接收3143块，其中2948块（93.80%）的自身收益头预测负增量。
- G_relation接收45块，45块收益预测全部为负。
- 在B稳定身份块上，关系头增量MAE=0.009272，恒预测0的MAE=0.001022；G对应0.011308与0.001324。
- **10个正式验证器在各自训练块上的增量回归MAE也全部差于恒预测0。** 因此不能仅归因于外折分布迁移，训练内收益拟合也未成立。
- B_relation对稳定父选中的2230块，只有176个满足安全真值，约7.89%；p(safe)>=.99的稳定块1051个，安全仅67个。置信数字不能当真实安全概率，调高门并没有已证实保障。

这不意味着立即追加“预测delta>0”的新开关：当前delta头本身不可靠，增加这个条件可能只会清空动作。应先在训练和内部留出上让后果预测胜过常数基线，检查各任务损失尺度与收敛、未知身份拒绝和概率校准，再决定如何使用预测后果。

## 4. 区域关系表示仍是摘要，没有真正读取局部边界结构

`descriptor`把每个区域的64维点特征和3维概率压成均值、标准差、XYZ范围、点数和可见性。关系网络在七个区域摘要之间做成对MLP及池化；不读取块内点排列、跨边界逐点对应或逐视角证据，也没有对其他拟删除块做联合动作推理。它保留空间统计，但不保留完整空间关系。

这符合本轮有限改编，并非实现冒充SSTNet；但不能用这一失败否定区域图、边界关系或局部重分割。当前有效纯块只有4个机会，继续依赖旧B高阈值碎片并堆摘要网络，实验空间非常有限。

## 5. 一个应修正但不能当主因的数值细节

`deletion_blocks`直接对float16概率比较Python浮点0.8，本环境中阈值按float16量化为0.7998046875；旧repair先转float32后比较。相对于明确float32的0.8，本轮B额外提议308点，其中182点属于稳定父目标；G多7点，其中2个为稳定父目标。它解释了部分细微提议差异，原已封存实际结果仍可复现。本审计没有重算改阈值后的全部连通块与网络输出，不报告修复该细节后的新收益。

未来新合同中统一float32概率比较，并加阈值边界用例；保留旧封存结果。

## 下一步：先做区域提议覆盖实验，再决定是否训练

**优先改N/T生成之后的局部区域产生方式，不改相机轨迹或GD10。** 新路线不是恢复不受控重复采样，也不是直接降低删除执行门。

1. **先生成不依赖G高置信通过的局部区域。** 固定现有父点集、可见性与点图，用空间邻接、几何/颜色边界形成有预算的多尺度区域；N/T分歧提供优先级，但不是唯一资格。划分在读取GT之前完成，不能只对这四个见证设计或挑选区域。不把ScanNet原分段的零混合当能力证明：GT也由这些分段聚合，优先用原始XYZ/RGB/法向重新形成区域。
2. **先检验提议是否保留机会和足够训练样本。** 在原外层训练范围内部，用GT只作标签/诊断，检查安全块、混合块、未知父、跨场景数量与尺度覆盖，以及整块筛查相对完整NT的潜在价值。与现有G提议作同输入对照。没有样本覆盖就停止，不自动训练验证器。该阶段产物应是固定区域清单、覆盖/尺度分布和可行几何收益表，不是AP。
3. **供给合格后再做同源学习。** 训练和测试使用同一个区域产生规则；若区域完全由冻结的非学习几何规则产生，无需专门为提议训练20个内层G。若仍引入学习生成器，则保留严格嵌套交叉预测。先有简单区域归属基线，再比较读取点/边界图的关系模型，避免同时替换提议、损失、表示和准入。
4. **训练验收先于外折验收。** 报告收益回归相对零预测、点损失比例误差、安全概率可靠性、稳定/未知父和尺寸分层；训练及内部留出未过关不进入完整外折评测。最终仍以真实点集的NT池增量、好父保护和漂移验收，纯GT筛查不能充当通过结果。

如果研究目的仅是补齐“B提议上的验证器是否有效”的归因，应另做同B配方的内交叉提议对照；旧B只能作为高召回提议基线，不直接执行，不混用旧全局OOF训练验证器。这能隔离迁移因素，但不会解决B整块机会只有4个的限制，因此不是优先的几何提升主线。

论文方法依据：[SoftGroup, CVPR2022](https://openaccess.thecvf.com/content/CVPR2022/html/Vu_SoftGroup_for_3D_Instance_Segmentation_on_Point_Clouds_CVPR_2022_paper.html)将软分组与后续精修分开，避免早期硬决定向后传播；[SSTNet, ICCV2021](https://arxiv.org/html/2108.07478v1)以区域及其交互修剪提议。这里借鉴“区域供给与精修分工”，不是复现两篇论文的完整实现，也没有证据保证迁移到当前NT池一定有效。
