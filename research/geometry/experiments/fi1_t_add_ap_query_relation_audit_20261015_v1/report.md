# T补点下游AP与query关系诊断：审计

审计对象为 `fi1_t_add_union_downstream_internal24_20261014_v1` 和 `fi1_query_relation_diagnostic_exposed52_20261014_v1`。本次只审计这两项实验及其直接实现，不展开重读历史。

## 结论

报告主要数值与结论得到保存产物复算支持。本次检查范围未发现足以推翻结论的实现错误。当前A/B补点规则没有获得下游AP支持；query关系诊断发现了可利用信息和少量机会，但没有产出已验证有效的自动修复方法。两者应区分。

不能把结果概括成“query无用”“所有多query方法无用”“再增加训练数据即可解决”。这两项实验没有训练新模型，也没有验证完整实例树。

## 下游AP说明什么

相对原NT，A追加语义AP下降1.045683个百分点，类别无关AP下降1.215296个百分点；B分别下降0.113399、0.315841个百分点。B动作少、损失小，没有取得正收益。

新增T可成为TP，却没有新增被检出的目标：它可以替代原来已经检出同一实例的N/T。新增错误、重复候选和评分/排序变化仍会降低AP。所有阈值目标集合不变支持这一解释，不能把下降简单写成“丢掉了许多目标”。

A_context只允许原候选进入输出，但使用扩展候选池计算上下文；语义AP已下降0.684227个百分点。A_append相对A_context再下降0.361456个百分点。这个固定对照把上下文影响与允许新增候选参与选择的影响拆开；并非精确逐候选因果分摊。B_context语义变化为-0.001932个百分点，主要下降发生在追加阶段。

因此，“没有几何池增量仍可能通过语义或排序提高AP”的原理并未被否定；这次实际测试证明，当前A/B在本冻结接入方式上没有做到。新增候选使用现有refined_union来源槽，结果也不能无限外推到所有新接入方式。不能据此在已暴露场景上反复试来源槽或评分配置挑选赢家。

语义新T入选685/158是类别成员条目，不是685/158个不同几何mask；类别无关实际新增入选mask为73/19。应防止把两种统计混用。

## query诊断中什么有用

有用的是“现有候选集合里已有部分缺失区域的信息”，以及对当前失败原因的定位：

|GT后置构造|完整NT增量至少0.02的目标|含义|
|---|---:|---|
|候选中最佳单query局部补点|6|有机会，但尚不能自动选出|
|全部150中最佳单query局部补点|6|扩大query列表在本读出方式下没有增加目标覆盖|
|最佳原锚+另一个query局部补点|6，目标集合相同|此固定组合方式没有增加独有机会|
|全部候选hard支持局部并集|2|把支持全部合起来会破坏部分可用机会|
|全部纯目标整块并集|5|存在整块选择机会；不是任意整块选择的理论最优|
|同域逐点目标补回最优|8|仅该采样父、可编辑域和加点任务内的参照|

六个单query机会来自internal24三个目标、fit12一个、exposed16两个。全部已暴露，不能作为独立泛化证据。数值是GT挑选后的潜力，不是可上线规则的产出，更不是AP改善量。不得用这些GT最优选择直接做正式预测。

两个反例有实际设计价值：

1. `scene0002_00/c006`：替代query q7对父主体硬覆盖0，却能提供有价值的缺失部分。因为原父保留，补片query无需独立重建整个父。把“高父覆盖/和原锚重叠”设成必需条件，会再次漏掉真正机会。
2. `scene0078_00/c004`：最佳单query补点仍比原NT差约0.01583，而纯整块构造可比NT好约0.02938。这里已有支持信息，直接读出query全部局部硬支持会混入错误区域；单纯换父query也不能解决。

这说明需要区分“某query支持这个块”与“该块属于待修复目标”，并限制实际补入范围。它没有证明已有证据足以安全解决这两个判断。

## 必须保留的限制

1. **最佳query对的范围。** 关系图记录了候选集合内全部两两关系，但池供给比较只试“固定原锚+一个候选query”，没有穷举任意两query、多query集合或条件选块。所以不能写成“所有query组合都不如单query”，更不能宣称完整Clutt3R-Seg式实例树已被否定。
2. **高AUC不是自动合并准确率。** 5707条关系中未知3350、混杂1349，占82.34%。高AUC来自特定可标注子集；同目标重复/互补类别本身又使用重叠阈值分组。它不代表在全部关系上有约94%或95%的安全判别能力。低重叠真实机会恰会被总体强信号排除。
3. **局部与全局安全分开。** 局部同目标不能证明全场景query直接取并集安全；反过来，query在远处污染也不自动否定严格限制在当前编辑块中的补点。必须评估实际输出点集。
4. **供给上限范围有限。** 本轮研究207个采样T父，GT供给主要针对143个稳定父的原目标、原halo及可见性约束，只允许补点。不能把8个目标当作整个Geometry研究方向的上限，也不能用结果判断N修复、删除或halo之外的机会。

## 研究决策

停止当前A/B补点规则的直接推进；暂不训练更大的统一修复网络，不直接构建自动实例树，也不把全部query支持并入父。

如果继续这一支，最小研究对象应是**允许拒绝的局部块归属与选择**：保留原父，复用现有query集合，允许缺块由非原锚query解释，但只考虑被判断属于该父的具体局部块。高父支持、query重叠、多帧共同支持均不能先验作为所有案例必需的硬条件。现有证据尚不足以指定一个保证有效的新规则。

开发阶段要同时检验“能否保留真正超过完整NT的机会”和“会不会接入邻物/未知区域”，覆盖全部负例而非只拟合这6个机会。尤其不能只追求平均关系AUC或原T的IoU改善。只有形成一个固定、可复现且实际保留池价值的无GT方案后，才值得到未参与规则设计的物理隔离场景验证，并按固定输出做下游AP对照。

若关键低重叠机会与邻物在现有证据下仍无法区分，应明确停止当前信息条件下的块归属路线；再研究新增观测、区域表达或可编辑范围，而非继续扫描旧阈值。两项实验目前支持的是这个研究边界，不是一个已经成功的新修复策略。
