## 最新200／55的可核查事实

训练200沿用既有SL名单，等于geometry development200，参考82是预先指定子集；训练与开发扫描及物理地点均无交集。全部255场景完成，无排除、无补选；scene0161_00零候选仍保留，199场景实际贡献7,154条明确监督。混合／未知不参与二分类拟合，但全部预测与评估。

同一开发55共4,014对。模型固定HGB：100轮、31叶、深度6、叶最小5、学习率.05、L2=5、种子20261015，无early stopping；场景等权，场景内自然类别比例。154维特征、.9／.1门槛、eligible、单伙伴竞争、完整并集和原NT保留均固定。

后置供给有10对／9目标／7地点，其中严格明确同实例7对／6目标／5地点；10对均eligible且分数未达.9，故不是伙伴竞争漏选。200模型对7个明确机会给分.368—.799，每个前有28—246个明确异实例对得分不低于它。逐对失败定位及该独立审计源码见[evidence.json](evidence.json)与[audit_train200_dev55.py](audit_train200_dev55.py)。没有依据这些机会调权重、阈值、模型或选场景。

同一82训练子集的困难loss .216673→.304053，不能归因于只改善记忆、泛化失败。本轮未单独区分容量、优化、摘要、监督或分布作用，也未证明200已经充分或所有学习方法无效。

## 来源、GT隔离与复算范围

- 合同、源码哈希和输出顺序沿用原实验记录，导出时核对每个绑定源码；evidence保留原始文件哈希和原路径。哈希与审计回执用于追踪，不能单靠哈希独立证明GT没有泄漏；守卫、训练／预测入口及补充允许路径也提供源码供审阅。
- 最新两个模型的分数／动作／并集先封存，再读开发GT。测量侧只修正scene0373_00第830帧两个相机后方可见标记；未改原mask、源缓存、候选和并集。旧82特征及训练行精确一致。训练标签哈希读取的守卫补充发生在拟合前，具体理由及源码绑定保留。
- 原独立复核覆盖255场景、38,382帧可见性、20,571对标签、462并集及2,370次池目标复算。后续独立审计重建开发55的IoU／身份并回放模型，没有再扫描全部原始帧。两者范围分别保存，不混称。
- 本包可独立复算最新关系loss、身份／风险计数、伙伴竞争、供给计数和目标标量汇总。运行 `python research/geometry/reviews/20261015_relations/verify.py`，仅用Python标准库，不训练、不读本机数据、不写实验目录。
- **从原始点索引重新计算IoU、重提154维特征或回放模型，仍需本机保留的点集、GT、RGB-D、模型及封存。** 它们不在GitHub；CSV中的IoU／身份是已计算证据，不是原始几何证明。旧轮仅保留核心指标与审计摘要，不能仅凭本包逐对复算旧轮的全部指标。
- 所有当前研究只追加候选。好端点副本损害不等于删除原NT，也不是已测AP损失。本包涉及的九轮未运行AP；更早24场景AP已执行，不受此表述覆盖。
