# SL最终单模型与独立验证安排

最终L训练名单固定为现有开发200的全部200个物理场景，逐扫描清单见final_validation_plan.json。训练一个28→32→1残差模型，沿用原损失、20轮、种子20261010和训练200自身的均值／标准差；种子沿用原版，事前确定，不按三套AP选择最好的一套。推理仍由冻结B26在完整S资格池上计算特征并选择800，单个L提供最终置信，实际去类从已选成员取最高分。不会将五折模型按场景路由或五折拼接分数当作最终部署模型。

先采用训练200是为了与本轮已经验证的候选／监督协议一致。扩展到597需要额外397的S对称资格及一致多档监督，属于新训练配置，不能把本轮五折结果直接宣称为597单模型结果。本轮只确定训练安排，不启动最终200训练。

当前未建立可称为全系统盲测的本地独立清单：开发200已反复查看；旧保留100已消费；验证312已有多轮历史结果；开发55和论文图例也不能直接登记为新盲集。本轮不读取这些集合的预测、标签或GT。它们以后若用于验证，只能按实际暴露历史报告，不能改称盲测。

优先选择官方ScanNet隐藏测试评测，或新取得并独立保留的场景集合。正式执行前须冻结真实扫描清单、物理场景映射、点序与输入哈希；核对与所有上游模型训练、597后端训练、开发／旧保留／历史验证及图例身份的交集，而不只与L的训练200比较。当前没有据此冻结一份实际独立清单，不能声称已经准备好盲测，也不访问隐藏测试资产或提交外部评测。

稳定性及核验完成后，先锁定独立清单和评测入口，再按上述固定200名单训练一个最终模型一次、封存权重和归一化。基线OpenYOLO3D、当前生产Full、SL须使用同一输入与原评测口径；先封存全部预测，再一次性评测原198类的类别AP及实际输出去类AP/AP50/AP25。预先报告所有场景和类别、失败／缺失场景，不按效果筛图或选场景、不据独立结果继续调参。独立验证没有GT可定义的424子群；本轮覆盖保护是相对固定S集合的结构性质，不是对独立集AP的保证。

只有这次单模型独立评测通过，才有新的最终方法证据。现有生产Full保持原登记状态。
